## 0. 一页结论
- 做什么：让「想尽早进真实科研」的北大大一大二，**自己读懂一个领域、找到值得做的问题、拿出老师认的证据，并走完从准备到进组的全过程**。不是问答，不是导师替身，不代写。
- 定位：学生会在另一个窗口开着自己的 Agent（Claude Code、Codex、DeepSeek…）。我们不和它比，而是做它工作其中的结构——**「我们让你的 Agent 更会做研究，让你的工作更可信」**。启研是地图、标准、领域工具包、核对过的机会和证据账本；学生的 Agent 是手（§1B.3）。
- 主轴（研究思维层，§1C）：读（阅读卡）→ 比（综合矩阵）→ 问（问题阶梯）→ 提（提案画布）→ 试（最小测试）。每一步都是固定形状的作品，引文必须能在原文里定位，模型只核对和发问，不替学生写。
- 楔子：「进组敲门砖」= 读目标课题组的论文 → 阅读卡 → 小矩阵 → 提案画布 → 最小测试的结果。老师看到的是「这个学生读过我们的工作，并且想清楚了一个小问题」，这正是灰色机构卖不出来的东西。
- 概念模型（备赛）：目标（有日期的比赛）→ 路线（训练计划）→ 动作（一次训练）→ 作品（有标准有裁判的成绩）→ 账本（训练日志）→ 机会（赛历与球探报告）→ 人（学长学姐、小组、老师）；领域工具包是教练组事先备好的录像和战术板。
- 循环：建档 10 分钟 → 每周排 3 个动作 → 做、交、评、改 → 过线进作品集 → 目标就绪度上升 → 联系 → 结果回写机会数据；进组后转为学长学姐（供给侧）。
- IA：今日 / 研读 / 路线 / 机会 / 作品 五个标签，账本在头像菜单「我」里；任务不再是导航项，而是全屏工作台；「项目」拆成机会（找）和作品（做），公开练手项目降级为提案画布里「最小测试」的候选。
- AI：我们自己的模型是裁判席上的零件，做八件受约束的活（抽取、摘要、排序、按标准评阅、按清单挑错、出讲解检查题、对照原文发问、核对决策日志与轨迹）；没有任何「问 AI」入口；关掉模型，每个主界面照样能完成主任务。裁判必须独立于选手的器械，这是我们仍需自己的模型的原因。
- 双窗口：每个动作都有「交给你的 Agent」简报（AGENTS.md / SKILL.md 式，带我们的标准、引文规则和诚信规则）；交回时带「决策日志」（Agent 建议了什么、我留了什么、拒了什么、为什么），可选附真实轨迹。评阅看判断，不只看产物：引文核对抓编造，决策日志对照轨迹，画布关口由真人做 5 分钟讲解，不监考、不录屏。
- 为什么通用 Agent 替代不了我们：核对过且持续刷新的机会数据、只有聚合用户才有的结果数据、经学长学姐核对的领域工具包、第三方持有的纵向证据、老师认的作品格式与过程证据、校内人际网络（§1B）。这些恰好是学生的 Agent 缺的输入和缺的公信力。
- 先做（2–3 周）：阅读卡模板 + 引文定位校验 + 一个手工领域工具包 + 由标准自动生成的 Agent 简报与决策日志 → 服务端账本与作品版本 → 一个方向 30–50 个课题组的核对数据 → 矩阵 → 提案画布与作品集 → 五标签 IA；模型措辞最后做；给学生 Agent 的只读 MCP 接口推迟。
- 先验证：老师会不会看作品集和过程证据（R1）；同一目标下「学生的 Agent 单独用」对「Agent + 启研」的正面对比，看事实错误、问题质量和是不是学生自己想的（R2）。
## 1. 我们到底在做什么
### 1.1 问题（按负责人修正后）
- 用户：北大（先北大，后同类高校）大一大二里「有野心、已经在卷」的那部分人：想尽早进课题组、拿本研 / 大创 / 挑战杯立项或奖项、有第一份署名或一封分量足的推荐信，为保研、直博、出国积累站得住的科研经历；他们读小红书 / 知乎 / B 站的科研入门帖、套磁、问学长学姐、同时用境内外的生成式 AI（Xie, Li & Cheng, 2025），其中一部分会付钱给科研辅导或背景提升机构。
- 他们要的不是被鼓励，而是：下一步做哪件事最值、做完别人认不认、离目标还差多少、什么时候现实。
- 产品负责人进一步指出：真正的能力是读论文、看出缺什么、判断哪个问题值得做。学生不应该对 Agent 说「给我找个项目」，而应该（哪怕借助 AI 间接地）自己弄懂他所在的那片领域。本文把这一点作为产品主轴（§1C）。
- 工作（JTBD）：「在绩点压力下，用最少的时间，把我变成一个老师愿意收的本科生，并且有证据证明这一点。」拆成六个子工作：①找对门（哪些组和计划收低年级、何时、要什么）②读懂一个小领域（读得动、比得出、看得见缺口）③提出一个站得住的小问题 ④拿出可被核对的作品 ⑤知道自己在哪（校准）⑥被真人接住（进组后有人带，产品退场）。
- 背景事实：本科生参与科研在中国是少数行为——一项覆盖 39 所高校的调查中，与老师一起做研究的本科生占 17.84%，「双一流」高校学生参与科研相关活动的比例为 38.14%，第一代大学生和农业户口学生参与更少（Ke et al., 2022）。本科生科研被列为高影响力教育实践之一（Kuh, 2008），越早接触研究，完成理工科学位的可能越高（Rodenbusch et al., 2016）。
- 北大的现实节奏：「本科生科研训练」面向大二及「学习成绩优秀、学术志向明确」的大一，有「导师公开题目（每题最多一名学生）」和「自主联系导师」两条路；2025 年 6 月中下旬截止申请、12 月中期、次年 10 月结题答辩（北京大学教务部，2025）。一个 10 月入学的大一，如果想走本研，春季就要有导师点头——产品必须把这种节奏摆到台面上。
### 1.2 一学期后的成功（可观测）
- 至少一张过线的提案画布：引用自己的阅读卡和矩阵格子，问题具体、一学期内做得完、写明什么结果会让自己改主意，并经学长学姐或助教看过。
- 至少一件过线的最小测试作品（复现、小实验、小数据分析），版本可追溯、附 AI 使用声明、老师 2 分钟看得懂。
- 对至少一个真实目标（课题组 / 本研 / 竞赛）走完「准备 → 联系 → 有结果」，结果记在看板上。
- 校准：学生对自己就绪度的估计与外部评审的差距缩小。进组或立项是期望结果，但不承诺一学期内必然发生；不把它当唯一成功标准，否则会诱导造假和刷量（§12）。
### 1.3 不为谁
- 想买论文、挂名、找人代写的人：拒绝，并写在首页——这是对机构的差异化。
- 已在组里有稳定导师的人：只在「成为学长学姐」这一侧接住他们（§5.11）。
- 只要书单和泛泛建议的人：通用聊天已经够了（§1B）。
### 1.4 同意 / 不同意
- 同意原推断：信息不对称、起步门槛、脚手架与渐退、可审查的用户模型、对事不对人——机制保留，服务对象变了。
- 不同意原推断：「害怕被评价」不是这群人的主障碍。他们的主障碍是**没有可被认可的信号**（大一只有一学期绩点）、**节奏不现实**（幸存者偏差的帖子）、**把思考外包**（让 Agent 读论文、出题目，结果学不到也证明不了）、**人脉不均**。重心从「建立自我效能」移到「自己产出可核对的思考证据 + 诚实校准」。
- 对负责人修正的两点挑战：①最顶尖、人脉最好的学生（例如已在拔尖类项目里有导师的，各项目导师制细节「未核实」）未必需要我们；价值最大的是**有野心但缺人脉**的人——最可能去找机构、最受学长学姐信息不均之害。滩头先打这一群，§15 验证。②「每天用」不是科研的真实节奏：科研是截止驱动加周节奏；北极星定为「每周过评阅的证据数」，日活只在冲刺期自然出现。为日活设计会把产品推向打卡和推送，正是 §11 要避免的。
- 课程约束（每次交互落到一件具体的事、不编造、面向大一大二、先展示结果再改代码）全部保留：它们正好构成对机构和对聊天工具的差异化。

| 树洞 / 院系通知 | 实时、真实 | 噪音大、搜不到、匿名不可核对 | 结构化 + 核对 + 截止提醒 | 截止雷达 |
### 1A.3 楔子：进组敲门砖
- 定义：选一个核对过的组 → 读它近两年的 2–3 篇论文（阅读卡）→ 拼成小矩阵 → 在矩阵上找一个空格或冲突并论证它为什么重要 → 写一张提案画布 → 跑一个两周内做得完的最小测试 → 在套磁准备台写信（学生自己写，系统按清单挑错）→ 看板追踪。
- 为什么是它：①这群人最在意、信息最不对称的一步；②可测量（发了没有、回了没有、进了没有）；③它是灰色机构卖得最贵的东西的合法版本；④它把产品负责人要的「读论文、找问题」直接变成进组的通货；⑤同一件作品可复用到本研、大创、推免材料。
### 1A.4 增长回路
1. 作品回路：学生在套磁信、本研申请、简历里放作品集链接 → 老师和同学看到「标准公开、引文可查、版本可查」的作品页 → 同学来注册；老师看多了，开始在平台上标「本学期收本科生」→ 机会数据更新鲜。
2. 小组回路：小组 4–6 人才开张 → 学生拉室友和同专业同学 → 每周交付与互评留住人。
3. 学长学姐回路：进组用户转为供给侧——写组卡、核对领域工具包、发「试做任务」、看提案画布 → 低年级因此而来 → 他们进组后再变成学长学姐。动机：组里缺人手（招本科生是真实需求）、署名致谢、帮直系学弟学妹。
4. 内容回路：经同意，把匿名「从零到进组」轨迹（时间线 + 画布 + 节点）做成可分享卡片发到小红书 / 知乎——读者本来就在那里读这类帖子，我们给的是带凭据的版本。
5. 数据回路：每次联系结果（聚合、过阈值后）回写机会数据：「过去一学期 n 人联系、m 人有回复」→ 推荐更准 → 更多人用。
6. 简报回路：学生导出的 `AGENTS.md` / `SKILL.md` 头部写明「按启研标准 vX 生成」和工具包链接；它们会随学生的仓库和同学间转发传播，每一份都是一个指回启研的入口。
### 1A.5 护城河：哪些会积累，哪些不会
- 会积累：①核对过且持续刷新的机会数据；②结果数据（公开网络上不存在）；③领域工具包（经典论文与阅读顺序、标准数据集、作者原文写的开放问题、专家批注的示范卡），一次建好、学长学姐核对、带版本、所有学生共用；④标准：与北大老师和博士生共同签认的作品格式与评阅标准，认的人越多，按它做的学生越多；⑤校内网络：最小网络是「一个院系 × 一个方向」（Chen, 2021 的 atomic network）；⑥账本：第三方持有、带时间戳与版本的证据比自述可信（Spence, 1973; Donath, 2007），也形成迁移成本。
- 不会积累（不投入）：模型措辞、书单、选题点子、概念讲解、单篇文档润色。
### 1A.6 最危险的假设（按「错了就要重来」排序）
- R1 老师 / 博士生会看、并看重作品集，尤其是提案画布（信号有没有币值）。
- R2 同一目标下，「学生的 Agent + 启研」在事实正确、问题质量和「是不是自己想的」上胜过「学生的 Agent 单独用」（否则我们只是多一道手续）。
- R3 S1 学生会因为核对过的机会数据和领域工具包每周回来，信它胜过学长学姐 + 树洞 + DeepSeek。
- R4 一个方向的数据和一个子领域的工具包，能以可承受的人力保持新鲜。
- R5 学长学姐愿意供给（组卡、工具包核对、画布评审）。
- R6 「不代写、不替你读」的立场不赶走用户（或反而是卖点）。
- R7 小组提高交付而不加剧内卷焦虑。
### 1A.7 漏斗指标（先定义死）
- 获取：来源渠道（作品集链接 / 小组邀请 / 内容卡 / 学长学姐 / 其他）。
- 激活：注册 7 天内有一张过线的阅读卡（不是「聊完 5 个问题」）。
- 留存：第 1–4 周每周至少交一次动作的比例；北极星：每周过评阅的证据数。
- 推荐：每个激活用户带来的激活用户；作品集外链打开次数。
- 结果：联系数、回复数、面谈数、进组 / 立项数（学生自报 + 可选凭据）。
## 1B. 为什么不是一个聊天框 / 通用 Agent 做不到什么
### 1B.1 测试与定位
- 测试：一个每月付约 20 美元用 Claude Code / Codex / ChatGPT / DeepSeek、配了像样 harness 的学生，已经能拿到科研建议、阅读清单、项目点子和单篇文档的反馈。凡是能这样复现的，都不是我们的价值。
- 定位：我们不替代学生的 Agent，而是**让它更会做研究，并让学生的工作可信**。Agent 能做的（讲概念、跑代码、润色、对一篇文档提意见）是我们结构的输入；我们提供的（核对过的数据、标准、第三方账本、校内的人）是它缺的东西。
- 风险在于外包：Agent 越能干，学生越容易把读和想交出去——自报对 AI 信心越高的知识工作者，批判性思考越少（Lee et al., 2025）；无护栏的 GPT-4 辅助撤掉后学生表现更差（Bastani et al., 2025）。我们的结构让学生自己想，并且能证明是自己想的。
- 为什么我们仍要自己的模型：裁判必须独立于选手的器械。同一把尺子、规则为上限、引文逐字核对，评阅结果才对老师有公信力。
### 1B.2 结构件
| 结构件 | 通用 Agent 为什么不能便宜地重建 | 护城河 | 现有地基 |
| --- | --- | --- | --- |

- 我们自己的模型：八件受约束的活（§8.1），每件有固定输入、结构化输出、代码校验器、规则兜底。模型永远不是界面。
- 不变式：`LLM_API_KEY` 为空时，每个主界面都能完成主任务；现有代码已做到「失败回退规则」，写成测试并作为 PR 必过项。
- 文本输入只做结构化采集：每个框有字数上限、用途说明和去向；没有开放对话框。唯一和 AI 有关的按钮是「交给你的 Agent」，它导出文件，不开对话。
- 明确砍掉：旧分工里的「问导师」自由聊天页（TASK_ASSIGNMENTS §4）；画像的对话气泡形态（改为表单式建档）；任何「问 AI」「AI 帮你写」「AI 帮你找项目」按钮。
### 1B.3 双窗口：学生自己的 Agent 是手，启研是地图、标准和账本
- 设计假设（产品负责人）：学生会在另一个窗口主动用自己的 Agent。禁止不了，也不该禁止。课程本身就是这样训练的：isse-labs 的实验目录附 `AGENTS.md`，要求 Agent「思考题必须先让用户回答，不要先给标准答案」「不得替用户新增其没有表达过的核心观点」，并由学生把真实对话粘贴进 `AGENT_TRACE.md`，Agent 不得用总结冒充轨迹（isse-labs `lab2/AGENTS.md` 第 11、12、15 条）。我们把同一模式搬进科研训练。
- 分工：启研是记录系统（地图、路径标准、领域工具包、核对过的机会、证据账本、作品集）加裁判（引文核对、按标准评阅、决策日志核对）；学生的 Agent 是工作台（跑代码、查报错、解释概念、对学生的草稿提批评和问题）。
- 交出去：每个动作、阅读卡、画布、最小测试都有「交给你的 Agent」，生成一份简报：仓库型 Agent（Claude Code / Codex）下载 `AGENTS.md`（技能型 harness 用 `SKILL.md`）放进项目目录；网页型（DeepSeek / ChatGPT）复制同内容纯文本。简报由标准注册表自动生成，固定七段：①这一步交什么（如阅读卡六栏）②标准条目与版本 ③引文规则（每条给页码、必须逐字、找不到写「未找到」、不得编造）④诚信规则（不替学生写主张、「我会改什么」、矩阵论证、问题、画布；只批评和提问；思考题先让学生答）⑤资源（工具包论文、数据集、允许的来源）⑥交回格式（建议逐条编号，留给学生标「采纳 / 修改 / 拒绝」）⑦轨迹要求（由学生复制真实对话，Agent 不得生成摘要冒充）。
- 交回来：工作台「导入」接受三样：学生自己的产物（填进固定栏）；决策日志（按编号：Agent 建议了什么、我采纳 / 修改 / 拒绝、为什么，一行一条）；可选的真实轨迹（粘贴 Markdown 或分享链接）。导入时自动剔除疑似密钥与个人信息（沿用课程「检查 AGENT_TRACE 不含 API Key」的做法）。
- 状态：来自 Agent 的内容先标「Agent · 未核实」（虚线框、灰字）；引文定位通过、链接可达后变「已核实」；学生在决策日志里表态后变「我已采纳 / 我已拒绝」。只有「已核实 + 学生表态」的内容进入过线判定；Agent 给的引文定位失败标红「原文里找不到」，阻断过线。
- 把「会用 Agent 做研究」当成可核对的技能：①要批评不要答案（简报默认让 Agent 只提问题和反例）②核引文（所有 Agent 给的引用都过定位校验；「被拦下的 Agent 引文数」只给学生自己看）③记决策（决策日志是作品的一部分）。工具包附一份学长学姐的示范轨迹，批注「这里我让它挑错而不是改写」，和示范卡一样渐退。
- 以后再做：只读 MCP 接口，让学生授权自己的 Agent 读取工具包和机会数据（公开数据，可默认开）以及账本（个人数据，按类别单独授权、可随时撤销、访问留日志）；只读，不开放写入——Agent 不能替学生交作品或改账本。代价：授权后账本内容会进入第三方模型服务商，授权页必须写明（§12）。
- 对学生的 Agent 意味着什么：不再现编组名和截止（用机会数据）；按核对过的顺序读、用标准数据集（用工具包）；按同一把尺子挑错（用标准）；知道你已证明过什么（经授权读账本）；它参与做出的东西，经引文核对和决策日志背书后才拿得出手（作品集）。
## 1C. 研究思维层：读 → 比 → 问 → 提 → 试
### 1C.1 立场
- 产品主轴是学生自己完成的五件作品：阅读卡、综合矩阵、问题阶梯、提案画布、最小测试。前四件是「找问题」，第五件是「试问题」。其余一切（机会、路线、小组、作品集）都围着它们转。
- 依据：用结构化方式精读一手文献，能让本科低年级在一学期内提高读文献的自评能力、对科研过程的理解和认识论信念（C.R.E.A.T.E.：Hoskins, Stevens & Nehm, 2007; Hoskins, Lopatto & Stevens, 2011）；「找问题」是与「解问题」不同的能力（Getzels & Csikszentmihalyi, 1976）；把专家的思考过程显性化并逐步撤掉支架，是认知学徒制的核心（Collins, Brown & Holum, 1991）。
- 模型的规矩：不替学生读、不替学生填、不替学生出题。它只做两件事：对照原文核对学生写的东西（「你的卡写『可推广』，原文 §5 只在 X 上测试过」），以及按规则发问（「『人群』这一列 5 篇里有 4 篇是空的」）。有护栏、不给答案的 LLM 助手可以在真实课堂里大规模部署（Kazemitabaar et al., 2024）。学生自己的 Agent 在简报约束下做同样的事（挑错、提问、跑代码），它的产出按 §1B.3 的「未核实 → 已核实 → 学生表态」处理。
### 1C.2 阅读卡（每篇论文一张，固定形状）
- 字段：主张（作者说自己做成了什么；用自己的话写，附作者原句一条作锚点）· 证据（哪张图、哪张表、哪个数字）· 方法 · 假设（作者默认成立、但没检验的事）· 局限（**必须引用作者原文**）· 我会改什么（一句，学生自己的）。
- 规则：主张、证据、局限三栏必须带原文引文和位置（页码或章节），引文必须在论文文本里逐字找得到——沿用 `submission.py` 已经对 zip 评阅执行的规则；找不到就不能提交。「假设」和「我会改什么」不要求引文，但评阅会查它们是否与原文矛盾。
- 模型核对：主张是否夸大了原文（卡写「所有语言」、原文只测英文）；局限是否漏掉了论文自己的 Limitations 段（规则先查：论文有该段而卡里的局限引文不出自该段时提示）。输出只能是「位置 + 原文引文 + 问题」，不给改写。
### 1C.3 综合矩阵（论文 × 维度）
- 维度由领域工具包给出（例如：数据 / 任务、方法、对象或人群、指标、结果方向、作者自述局限、关键假设），学生可增列。格子由学生自己的阅读卡自动填入，模型从不填格子。
- 矩阵让缺口自己显形：空格 = 没人做过或你没读到；冲突格 = 同一指标结果方向相反（学生在卡上标结果方向，规则比对）；整列为空 = 这个维度大家都没检验（常常是隐藏假设）。Garrard 的矩阵法正是用这种表格组织文献综述（Garrard, 2020）。
- 防止机械「找空格」：Alvesson & Sandberg (2011) 批评「找缺口」只是在既有框架里补洞，主张「问题化」——挑战文献背后的假设。因此：学生选中一个空格、冲突或空列时，必须写三句论证：①这里被默认了什么 ②如果默认不成立会怎样 ③谁会在乎这个结果。对本科低年级，找缺口是合法的起点，「假设」一列是通往问题化的台阶。
- 模型发问（只发问）：「这一格是空的，是没人做还是你没读到？工具包里有 2 篇相关」「你把这两篇标成冲突，但它们的数据集不同」。
### 1C.4 问题阶梯与提案画布
- 问题阶梯：话题 → 问题 → 问题的意义，用 Booth 等人的句式「我在研究 X，因为我想弄清 Y，以便让读者理解 Z」（Booth et al., 2016）。评阅标准：具体（点名对象、变量、指标）· 一学期内可行（数据可得、算力够、在你的周时间预算内）· 写明什么结果会让你改主意（Platt, 1964 的强推断）· 指向矩阵里的至少一格。
- 提案画布（一页）：问题（阶梯第三级）· 已知（引用 ≥3 张自己的阅读卡）· 缺什么（指向矩阵格子并附 §1C.3 的三句论证）· 最小测试（≤2 周做得完；数据从哪来）· 预期与证伪（什么结果说明想法错了）· 需要谁帮（人，不是 AI）。形式参照 DARPA 的 Heilmeier 问题清单（你想做什么、现在怎么做、局限在哪、新在哪、怎么知道成了）。
- 最小测试的候选来自两处：领域工具包的标准数据集与基准；任务 3 检索到的公开项目——它们从「列表里挑一个」降级为「为画布里的问题挑一个试验场」。
- 画布评阅三层：规则（结构完整、引用的卡和格子都存在）→ 模型核对（画布里的说法与卡是否一致、证伪条件是否可观测）→ 学长学姐或助教评「值不值得做」（模型不判断意义）。过线的画布进入作品集，是主作品。
### 1C.5 领域工具包（离线建、人核对、共用、带版本）
- 内容：①经典论文与阅读顺序（每篇一句「为什么先读它」）②标准数据集与基准（链接、规模、能不能在笔记本上跑）③开放问题——**只收论文局限 / 未来工作段的原文引文**，带出处和位置 ④2–3 张专家批注的示范阅读卡和一张示范矩阵，批注写出「我为什么这样填」⑤矩阵维度模板。
- 生产：团队成员按模板起草 → 一位在该方向的学长学姐或助教逐条核对（引文定位、链接可达、阅读顺序）→ 发布带版本号与核对人 → 每学期复核一次。模型可以帮起草者做引文定位和链接检查，不能决定收什么。
- 为什么不让 Agent 现场学：现场学的结果每次不同、没人核对、引文可能是编的（Walters & Wilder, 2023）；工具包的价值正在于「被核对过、所有人用同一版」。
- 每个学生看到的模型只是核对者和发问者，工具包里专家的推理（示范卡批注、开放问题的原文）就是学生「间接从 AI 系统学」的那部分——它是被人核对过的示范，不是模型的临场发挥。
### 1C.6 示范与渐退
- 顺序：示范卡（专家全填 + 批注）→ 提示卡（部分字段预填，其余给位置提示，如「看 §6 第二段」）→ 独立卡。矩阵和画布同样三档。依据：从示范学习的原则（Atkinson et al., 2000）；从示范到独立解题逐步撤除（Renkl & Atkinson, 2003）；已经会的人再看示范反而有害（Kalyuga et al., 2003）。
- 渐退按证据走：某字段连续两张卡过线，下一张就不再给该字段提示；学生也可以直接选「独立卡」，过线即视为会了。
### 1C.7 文献从哪来（大陆现实，均需在大陆网络下实测）
- arXiv：开放获取，主流 AI / 数学 / 统计论文都在；境内访问速度不稳，官方与中科院镜像已停止更新或下线（「未核实」）。用 arXiv 编号链接，由服务器取 PDF。
- 北大图书馆订阅库：校内 IP、VPN（vpn.pku.edu.cn）或 CARSI 校外访问，覆盖知网、IEEE、Springer Nature、爱思唯尔等（北京大学计算中心；北京大学图书馆）。只能由学生本人下载后上传，系统不抓取。知网部分文献是 CAJ 格式，上传前需另存为 PDF（「未核实」比例）。
- 中国科技论文在线（paper.edu.cn）：教育部科技发展中心主办，全文免费下载。
- Semantic Scholar、OpenAlex：用于元数据和开放获取链接；境内可达性「未核实」——任务 3、4 的链接核对出口 IP 在台北（TASK3 文档已注明），需在大陆复测。Google Scholar 境内通常无法直接访问（「未核实」）。
- 进入方式：开放获取论文用链接，服务器抓取；订阅论文由学生上传，**只供本人使用**，不在学生之间共享全文；领域工具包只存元数据和短引文（著作权法第二十四条允许为介绍、评论或说明问题适当引用并指明出处）。
- 技术风险：双栏排版、公式、连字、断行会让逐字匹配失败。做法：规范化后匹配（去连字符、统一空白与全半角），失败时允许学生补页码，由评阅标「未自动定位」，不阻断但不进作品集。
### 1C.8 难在哪，2–3 周做得到哪些
- 做得到：阅读卡模板 + 引文定位校验（复用 `submission.py` 的逐字核对）+ 示范卡与提示卡 + 由标准生成的「交给你的 Agent」简报与决策日志栏；一个人工搭建的领域工具包（一个子领域，约 8–12 篇论文、3 个数据集、5–10 条原文开放问题、2 张示范卡），由一位学长学姐核对；矩阵视图（从卡自动生成，空格 / 冲突 / 空列用规则标出）。
- 勉强做得到：问题阶梯与画布的表单、规则评阅和学长学姐人工评审流程。
- 之后再做：模型对照原文的核对与发问（先规则后模型）、知网 / 中文 PDF 的稳健抽取、更多子领域工具包、工具包的学长学姐协作编辑、画布评审的供给网络。
- 子领域选择（团队与学长学姐定，建议）：人工智能方向下「大模型评测与基准」——论文大多在 arXiv 开放获取，局限段常讨论数据污染与指标问题，最小测试能在小模型或小子集上跑；北大有哪些组在做需核对（「未核实」）。经济方向「最低工资的就业效应」是天然的冲突矩阵示范，作为第二个工具包候选。
## 2. 用户与情境
> 以下四个情境由公开材料和团队已知情况合成，**不是访谈结果**；§15 的访谈要逐条证实或推翻。

- A｜大一上 · 10 月 · 信科 · 想进 NLP 组（S1）。时刻：刷到「大一就进组」的帖子，室友已经在跟一个博士生做数据。怕：落后、邮件被无视。约束：每周能挤 6–8 小时，期中在即。没有我们：照模板群发十封套磁信，或让 DeepSeek「推荐几个适合本科生的 NLP 项目」。第一件事：在机会里把一个核对过的组加进看板，打开它一篇论文的提示卡，今天交出第一张阅读卡。
- B｜大一下 · 3 月 · 元培 / 经济 · 想走本研自主立项（S1/S2）。时刻：看到教务部通知，6 月截止，要先有导师同意。没有我们：问学长学姐要往年题目，或找机构「科研项目」。第一件事：路线把 6 月截止倒推成 12 周，标出「4 月前要有导师点头」；本周两张阅读卡，读目标老师的两篇实证论文。
- C｜大二上 · 数院 · 想转 AI 理论，有课程基础但没有作品（S2）。时刻：看到同学有复现报告。在考虑机构的「科研项目 + 推荐信」。第一件事：用「交证明跳过」让前三步按现有课程作业判过，直接用工具包的示范矩阵开始读。
- D｜大二 · 已进组两个月 · 被派清数据（S3，供给侧）。时刻：学弟学妹反复问「怎么进你们组」。想要：省时间、给组里招到靠谱的本科生、自己从打杂到有贡献。第一件事：10 分钟填组卡；花一小时核对本方向工具包的 3 条开放问题引文；之后看到学弟学妹的画布时，只评「值不值得做」。
## 3. 设计原则
1. **学生做思考，Agent 做手，系统做核对。** 依据：无护栏的 LLM 辅助撤掉后学生更差（Bastani et al., 2025）；对 AI 信心越高、批判性思考越少（Lee et al., 2025）；认知强制设计减少过度依赖（Buçinca et al., 2021）。后果：阅读卡的主张与「我会改什么」、矩阵论证、问题、画布由学生写；学生的 Agent 按简报只批评、提问、跑代码；我们的模型输出只有「位置 + 原文 + 问题」；评阅看决策日志里的判断，不只看产物。
2. **证据先于建议。** 依据：可审查的学习者模型（Bull & Kay, 2007, 2016）；人–AI 交互准则「说清为什么」（Amershi et al., 2019）；推荐解释（Tintarev & Masthoff, 2007）。后果：每个「下一步」挂 ≤3 个证据片（账本条目 / 作品评阅 / 截止），点开是原文；没有证据的建议不出现。
3. **引文可定位，查不到就说查不到。** 依据：LLM 生成参考文献的编造率（Walters & Wilder, 2023）；信息觅食理论中「信息气味」决定人往哪找（Pirolli & Card, 1999）。后果：卡、工具包、机会的每个事实字段都有来源和位置或核对日期；未知就显示「未知」并给获取路径。
4. **标准先公开，过线可改。** 依据：学生要先知道「好」长什么样（Sadler, 1989）；评分标准用于形成性评价（Panadero & Jonsson, 2013）；掌握目标结构（Ames, 1992）。后果：动手前看到标准；结果是「过线 / 未过线 + 改哪一处」；可以无限改，历史可见。
5. **示范在前，支架渐退。** 依据：认知学徒制（Collins, Brown & Newman, 1989; Collins, Brown & Holum, 1991）、支架（Wood, Bruner & Ross, 1976）、最近发展区（Vygotsky, 1978）、示范与渐退（Renkl & Atkinson, 2003）、专长逆转（Kalyuga et al., 2003）。后果：示范卡 → 提示卡 → 独立卡；会了就撤，允许交证明跳过。
6. **作品是信号，过程是防伪。** 依据：信号理论（Spence, 1973）、难伪造的信号（Donath, 2007）；招聘方从 GitHub 活动痕迹推断能力并认为比简历可靠（Marlow & Dabbish, 2013）。后果：作品集展示版本历史、引文定位、评阅出处、AI 使用声明、讲解检查；不展示任何对人的判断。
7. **诚实校准。** 依据：过度自信导致学得不够（Dunlosky & Rawson, 2012）；信任应与能力匹配（Lee & See, 2004）。后果：每个目标显示官方节点 + 你的现有证据 + 按周时间推的估计，写明依据；数据不够写「数据不足」，绝不编基率。
8. **一个最高杠杆的下一步，再加一周。** 依据：具体而有挑战的目标（Locke & Latham, 2002）；执行意图（Gollwitzer & Sheeran, 2006）；自我调节的计划—执行—反思循环（Zimmerman, 2002）；但规划类干预在大规模在线环境里效果有限（Kizilcec et al., 2020）。后果：今日一个主动作；周一排 3 个动作落到时段；周日回顾；不做每日清单。
9. **对事不对人，只和标准比，然后交给真人。** 依据：指向自我的反馈削弱表现（Kluger & DeNisi, 1996）；排行榜和徽章在一学期里降低内在动机（Hanus & Fox, 2015）；本科科研的收益主要来自与导师和课题组的关系（Thiry & Laursen, 2011; NASEM, 2017）。后果：不做排行、连胜、经验值；路线终点是一个真实的人或组；进组后产品退场。
## 4. 概念模型
### 4.1 隐喻：备赛，不是导师
- 目标是一场有日期的比赛；路线是训练计划；动作是一次训练；作品是有裁判、有标准的成绩；账本是训练日志；机会是赛历和球探报告；领域工具包是教练组事先备好、核对过的录像和战术板；学长学姐和小组是队友；学生自己的 Agent 是他带来的器械和陪练（力气大、但不认识赛道，也不能替他上场）；我们的模型是裁判席和录像分析（指出哪一帧动作变形、按规则打分）；启研整体是训练计划、成绩册和赛历。
- 为什么：①这群人的动机是外在的、截止驱动的，备赛让它正当；②教练说实话，诚实校准自然；③没人能替你跑比赛，「不代写、不替你读」自然；④教练会把队员送进队伍，「交给真人」自然。
- 不选「导师」：夸大 AI、和真导师竞争；不选「地图」：太被动；不选「聊天伙伴」：正是通用 Agent 的形态。
- 「备赛」只是设计内部的隐喻，UI 不写「比赛」「训练营」，避免把科研说成竞技。

- 用：目标、机会、组、计划、截止、工具包、阅读卡、矩阵、空格、冲突、问题、提案、最小测试、标准、过线 / 未过线、作品、版本、作品集、账本、已证明 / 自述 / 推断、下一步、本周、看板、学长学姐、小组、核对于某日、未知、原文第几页、交给你的 Agent、决策日志、轨迹、Agent · 未核实 / 已核实。
- 不用：画像（被打分的感觉）、AI 导师、智能推荐、为你定制、打卡、连胜、等级、能力值、0–100 分、天赋 / 潜力 / 适合你、「AI 为你找到的选题」。
- 尺度一眼可分：「步」是一学期尺度（阶梯），「动作」是一次工作；沿用任务 4 已定的「主干讲走到哪、节点讲二十分钟一件事」。
## 5. 核心交互循环
### 5.1 节奏与触发
| 触发 | 时机 | 学生看到 | 落到的一件事 |
| --- | --- | --- | --- |
| 首次进入 | 一次 | 建档（≤10 分钟）+ 一张示范卡 | 今天交第一张提示卡（≤40 分钟） |
| 周一（学生可改） | 每周 | 系统按规则排好 5 个候选动作 | 选 3 个放进时段 |
| 打开今日 | 学生主动 | 1 个主动作 + 证据 + 截止雷达 | 开始这一个 |
| 评阅完成 | 事件 | 过线 / 未过线 + 改哪一处 | 改一处再交，或进下一个 |
| 矩阵出现新空格 / 冲突 | 事件 | 矩阵上的标记（无弹窗） | 选一格写论证，或继续读 |
| 关注的机会 ≤7 天截止 | 事件 | 一条提示 + 就绪度缺口 | 补缺口的那个动作 |
| 关注的机会数据变化 | 事件 | 机会页「变化」标记 | 看一眼，决定留不留 |
| 联系后 7 / 14 天无回复 | 事件 | 一次跟进建议（只一次） | 发一次跟进或标「没回复」 |
| 7 天没有交付 | 事件 | 一条安静提示：最小动作 + 影响哪个截止 | 做，或暂停目标 |
| 周日 | 每周 | 本周交付回顾 + 小组互评 | 互评一份同伴作品 |

- 提醒默认每周不超过 3 条，学生可再调低；渠道是站内加学生选的一个外部渠道（邮件或微信服务号，接入可行性「未核实」）。依据：打断提高速度也提高压力（Mark, Gudith & Klocke, 2008）；calm technology（Weiser & Brown, 1996）。
### 5.2 首次（≤10 分钟建档，≤40 分钟第一件作品）
- 建档是表单：①目标类型 ②方向（可多选或「不确定」）③目标学期 ④每周小时 ⑤已有证据：勾选修过的北大课程（真实搜课）、贴 GitHub / 竞赛链接（记为「自述」）⑥一句话：你想弄清什么（≤60 字，结构化采集）。
- 输出：路线草稿（目标 + 现实节奏 + 六步里可能已过的步骤）+ 工具包里的一张示范卡 + 今天的动作：「照着示范，给工具包第 1 篇论文填一张提示卡」。激活定义（7 天内一张过线阅读卡）当天就能达成。
- 可选一步（30 秒）：「你平时用哪个 Agent？」选 Claude Code / Codex / DeepSeek / ChatGPT / 不用，之后的简报按它的格式导出；不用 Agent 的学生不受任何影响。
### 5.3 典型一周
- 周一 5 分钟：本周排程，系统给 5 个候选（例：2 张阅读卡、1 次矩阵论证、1 个复现小步、1 次套磁准备），学生选 3 个拖进时段；超出周预算时提示「超出 X 小时，考试周建议减到 2 个」。
- 平日（双窗口）：今日 → 打开工作台 → 「交给你的 Agent」导出简报 → 在 Agent 窗口里读、跑、让它挑错 → 回到工作台填自己的产物、导入决策日志（可附轨迹）→ 规则评阅、模型核对 → 未过线改一处 → 过线进账本。不用 Agent 的学生跳过导出与导入两步，其余相同。
- 周日 10 分钟：交付回顾自动汇总；小组互评一份；系统重排下周。
### 5.4 交完一个动作
- 评阅只有两态：过线 / 未过线。未过线时主按钮是「改这一处」（同一工作台，带上一版），次按钮「先放着」——不强制，但阶梯和矩阵只认过线的作品。现在的「进入下一节点」不论过没过都放行，要改。
- 过线：账本新增「已证明：能在论文里找到并引用作者自述局限（卡《…》v2）」这类可核对的条目；对应缺口消失，今日随之变。
### 5.5 从矩阵到画布
- 第三张卡过线后，矩阵出现；系统不推荐格子，只标出空格、冲突和空列。学生选一格写三句论证（§1C.3）→ 问题阶梯 → 画布 → 规则与模型核对 → 学长学姐评「值不值得做」（48 小时内无人接单则排队提示，不由模型代评）→ 过线进作品集。
- 画布的「最小测试」字段打开候选：工具包数据集 + 任务 3 公开项目（按画布的数据需求过滤），学生选一个、写为什么。
### 5.6 联系课题组
- 套磁准备台（§7.7）：学生填三格并选附哪几件作品；清单挑错不改写；产品不代发邮件。
- 同时「已发未回」的联系不超过 3 个（可调，调高需确认），保护老师也逼学生写好。回复后，面谈准备是一个 2 小时动作：再读对方一篇论文、写 3 个具体问题；结果拖到看板。
### 5.7 卡住了
- 「卡住了」是按钮：选类型（读不懂这段 / 环境跑不起来 / 找不到数据 / 不知道下一步 / 没时间）+ 一句话。
- 系统返回其中一种，都落到一件事：①降一级（换回提示卡、换一篇工具包里更早的论文、把动作拆小）②一条核对过的资源 ③「问人」：带问题模板去小组、学长学姐答疑或课程助教。
- 同一处卡两次：建议绕道；三次：只给「问人」。
### 5.8 失去动力
- 7 天无交付：一条安静提示（不说「你已经 7 天没来」），给最小动作、它影响哪个截止和「暂停目标」按钮。暂停后不再提醒，恢复时重排。
- 考试周：建档时问或从课程推出，自动减到 1 个动作或暂停。
### 5.9 换方向
- 显式决定：显示「带得走的」（读论文、写阅读卡、复现这类跨方向已证明条目）和「留下的」（方向专属步骤与卡），生成新阶梯和新工具包入口。
- 不惩罚换方向；摇摆的人可设目标「先摸清方向」：两周内在两个方向的工具包里各交两张阅读卡，再决定。
### 5.10 两周后回来
- 第一屏是「你不在的两周」：过了哪些截止、新出了哪些机会、关注的组卡和工具包有什么更新、小组交付了什么；按钮「两分钟重排」。没有断掉的连续天数，因为本来就没有。
### 5.11 进组之后
- 目标标为「达成」，切到轻量模式：组会前的阅读卡、本研 / 大创申请（复用画布）、阅读记录。
- 邀请成为学长学姐：写组卡、核对工具包、评画布、发试做任务；贡献署名。产品承认「你已经有真导师了」，不再给方向建议。
## 6. 信息架构与导航
- 五个标签：今日 / 研读 / 路线 / 机会 / 作品；手机底部五个标签（现在顶栏横排六个，390 宽已经挤）。账本放在头像菜单「我」（含账本、建档修改、隐私与导出、我的 Agent：导出格式、轨迹的默认公开范围、以后的 MCP 授权），并在每个证据片上一键直达——它是被频繁「引用」而不是被频繁「访问」的地方。每个机会、作品、作品集、组卡、工具包都有稳定链接（作品集要能放进邮件）。
- 全屏工作台（填卡、写论证、写画布、做测试、交、看评阅、改）从今日、研读、路线打开，不占导航：它是模式，不是地方。工作台顶栏固定两个动作：「交给你的 Agent」（导出）和「导入」（产物 + 决策日志 + 轨迹），这是两个窗口之间仅有的两个接口。

| 现在 | 去向 | 理由 |
| --- | --- | --- |
| 今日 | 今日（加本周、截止雷达、小组） | 唯一重点不变，补上证据和目标 |
| 画像（对话 + 核对） | 建档表单 + 账本 | 不聊天；「核对」是账本的一个筛选（待确认） |
| 方向（六棵树 + 主干） | 路线 | 主干六步 = 阶梯；概念树降为每一步里的「参考地图」 |
| 任务 | 工作台（非导航） | 任务是动作的执行面，不是目的地 |
| （无） | 研读（工具包 / 阅读卡 / 矩阵 / 问题与提案） | 新主轴 |
| 项目 · 找项目 | 机会（课题组、计划、竞赛）；公开练手项目降为画布「最小测试」候选 | 先有问题再挑试验场 |
| 项目 · 我的项目 | 作品 | 与卡、画布、测试同为作品 |
| 记录 | 账本（「我」菜单） | 合并 |

- 为什么是这五个：学生的一周是「今天做什么（今日）→ 读和想（研读）→ 离目标多远（路线）→ 敲哪扇门（机会）→ 拿得出什么（作品）」，五个标签对应五个问题，不重叠。小组暂不单列（周节奏，在今日有入口）。
## 7. 关键界面
每个界面写：要完成的事 · 内容优先级 · 状态 · 模型做什么 / 规则决定什么。五张线框：今日、阅读卡、矩阵、机会、作品集。
### 7.1 今日
- 要完成的事：3 秒内知道现在做哪件事、为什么、离哪个截止多近。
- 优先级：主动作（标题 + 尺寸 + 截止）> 为什么（≤3 个证据片）> 本周 3 个动作状态 > 截止雷达（14 天内）> 小组（本周谁交了、待你互评）。
- 状态：未建档 → 只显示「建档」；有目标无本周计划 → 「排本周」；评阅中 → 主卡写「评阅中」，其他照常；机会核对日期超过 30 天 → 雷达条目标「待核对」；模型不可用 → 理由显示规则版并带「规则」小标。
- 规则决定：哪一个动作（§8.2）、证据片选哪几条。模型只做：在规则选出的前 3 个里重排并写一句理由，理由引用的证据 id 必须在传入列表里。

```
┌ 今日 ──────────────────────────────────────────────────────────┐
│ 目标：进一个 NLP 组（2027 春）· 就绪度 2/4 · 本周 1/3             │
│ ┌ 下一步 ────────────────────────────────────── 40 分钟 ┐       │
│ │ 给《X 组 2025：……》填一张阅读卡（提示卡）               │       │
│ │ 为什么：[目标：X 组 · 关注中] [缺口：读过该组 0/2 篇]   │       │
│ │        [依据：10/2 阅读卡《……》v2 过线，局限一栏已独立] │       │
│ │ [开始]  [换一个]  [卡住了]                               │       │
│ └──────────────────────────────────────────────────────────┘       │
│ 本周  ✓ 阅读卡：工具包第 3 篇  ○ X 组论文卡  ○ 矩阵：选一格写论证   │
│ 截止  10/20 挑战杯校赛报名（核对于 10/01）· 11/05 X 组招新说明会     │
│ 小组  4/5 人本周已交 · 待你互评 1 份                                 │
└───────────────────────────────────────────────────────────────────┘
```

- 手机：主卡占首屏；本周、截止、小组折叠成三行摘要。「换一个」打开本周候选列表（不是对话）。
### 7.2 研读 · 阅读卡（工作台）
- 要完成的事：把一篇论文读成一张别人能核对的卡。
- 优先级：原文（左，可滚动、可选中文字）> 卡（右，六栏）> 示范 / 提示（可折叠）> 核对结果。
- 交互：在原文里选中一段 → 点「引为证据 / 引为局限」→ 引文和页码自动进入对应栏，避免手抄出错，同时天然满足「可定位」。学生仍需用自己的话写主张和「我会改什么」。
- 状态：PDF 抽取失败 → 「无法自动定位，可手填页码」（不阻断，标「未自动定位」）；引文对不上原文 → 该栏红框「原文里找不到这句」；示范档 / 提示档 / 独立档在顶部显示。
- 规则决定：引文是否逐字存在、必填栏是否齐、Limitations 段是否被引用、Agent 建议是否都已表态。模型只做：对照原文指出主张是否超出证据（输出：卡上那句 + 原文那句 + 位置 + 一个问题）。
- Agent 建议区：导入的每条建议是一个虚线框，状态只有「未核实 / 已核实 / 原文里找不到」，学生必须逐条「采纳 / 改 / 拒」才能交；「主张」和「我会改什么」两栏若与导入的 Agent 文本高度重合，标「与 Agent 输出重合」，该栏不计过线（其他栏允许采纳）。

```
┌ 阅读卡 · 提示档 ── 《……》(arXiv 2501.xxxxx) ── [交给你的 Agent ↗] [导入] ┐
│ 原文                                 │ 主张  [我的话：……]               │
│ §1 … we show that …                  │ 证据  「…」p.6 表 2 ✓已定位        │
│ §5 Limitations: We only evaluate on  │ 方法  [……]                       │
│    English benchmarks …   [引为局限] │ 假设  [……]  提示：看 §3 数据切分   │
│ §6 Future work: …                    │ 局限  「We only evaluate on …」p.9 ✓│
│                                      │ 我会改什么 [……]                   │
│ ── Agent 建议（来自 Claude Code，导入于 10-12）────────────────────── │
│ ┆A1 「方法栏可以补上 few-shot 的样例数」  已核实 ✓  [采纳][改][拒]   ┆ │
│ ┆A2 引用 Smith 2023 支持主张        原文里找不到 ✗（阻断过线）      ┆ │
│ ┆A3 「假设：测试集未出现在预训练中」  未核实   我：拒，理由 [……]    ┆ │
│ ── 核对 ──────────────────────────────────────────────────────────── │
│ ! 主张写「多语言上都更好」，§5 p.9：「only evaluate on English」。      │
│   这两句能同时成立吗？                     [我已改] [我不同意，理由…] │
│                                        [交] [看示范卡] [附轨迹（可选）] │
└──────────────────────────────────────────────────────────────────────┘
```

- 手机：原文与卡改为上下两个标签页；引用操作通过长按选中文字完成。手机上以读和改为主，首张卡建议在电脑上做（提示一次，不强制）。
### 7.3 研读 · 综合矩阵
- 要完成的事：一眼看出这几篇论文之间缺什么、哪里打架、什么从没被检验。
- 优先级：表格（行 = 论文，列 = 维度）> 标记（空格 / 冲突 / 空列）> 选中格子的论证区 > 工具包相关论文提示。
- 状态：卡少于 3 张 → 显示示范矩阵并写「再交 N 张卡后生成你的矩阵」；某格来源卡未过线 → 格子灰显；学生增列 → 已有卡的该列为空，提示可补。
- 规则决定：格子内容（只来自学生的卡）、空格 / 冲突 / 空列的判定。模型只做：针对学生选中的格子或标记提一个问题（如「你标的冲突来自不同数据集，还算冲突吗？」），不填格子、不推荐格子。

```
┌ 矩阵 · 大模型评测（工具包 v1.0）────────────────────────────────────┐
│            数据/任务   方法     对象      指标     结果方向  假设       局限     │
│ 论文 A     MMLU       few-shot  英文     准确率    ↑        测试集未泄露  只测英文 │
│ 论文 B     MMLU       CoT       英文     准确率    ↓ ⚡      ·            「…」    │
│ 论文 C     自建       few-shot  中文     人工评分  ↑        ·            ·        │
│ 论文 D     ·          …         英文     准确率    ↑        ·            「…」    │
│ ⚡ A/B 在同一指标上方向相反   · 空格   「假设」列 4 篇中 3 篇为空           │
│ ── 选中：「假设 · 论文 B」──────────────────────────────────────────── │
│ ① 这里被默认了什么 [……]  ② 如果不成立会怎样 [……]  ③ 谁会在乎 [……]      │
│                                              [存为问题的起点]          │
└──────────────────────────────────────────────────────────────────────┘
```

- 手机：矩阵改为「按维度看」的卡片列表（每个维度一屏，列出各论文的值和标记），不硬塞横向大表。
### 7.4 研读 · 问题阶梯与提案画布（工作台，无线框）
- 问题阶梯：三格句式「我在研究 X / 因为我想弄清 Y / 以便让读者理解 Z」，每格下方显示对应评阅条目（具体、可行、证伪、指向格子）。
- 画布：六栏（问题、已知、缺什么、最小测试、预期与证伪、需要谁）；「已知」只能插入自己的卡（自动带引文），「缺什么」只能插入矩阵格子（自动带三句论证），「最小测试」打开候选（工具包数据集 + 任务 3 公开项目）。
- 状态：引用的卡被改成未过线 → 画布标「依据变动」；学长学姐评审排队中 → 显示排队状态和预计时间（有数据才显示）。
- 规则决定：结构完整、引用存在、最小测试在周预算内；模型只做：一致性核对与证伪条件是否可观测；学长学姐决定「值不值得做」。
### 7.5 路线（无线框）
- 要完成的事：一页看清目标在哪、我在哪、还差什么、时间够不够。
- 优先级：时间线（今天 → 官方节点 → 目标日期；估计段画虚线并写依据）> 就绪度缺口清单（每条一个动作）> 六步阶梯（已证明 / 进行中 / 未开始 / 交证明跳过）> 参考地图（原概念树，可选浏览）。
- 研究思维层在阶梯中的位置：六步路径的「读论文」「复现」「小研究」三步分别以阅读卡与矩阵、最小测试、提案画布为过关作品；前面的技能步骤（先修、经典方法、工具）与研读并行，不必走完才开始读——C.R.E.A.T.E. 的证据表明低年级在支架下就能读一手文献。
- 规则决定一切（节点、缺口、状态）；本界面不出现模型文字。没有官方来源的节点画问号并给获取路径。
### 7.6 机会（库 + 组卡 + 看板）
- 要完成的事：找到「现在能敲的门」，并追踪敲了哪些。
- 优先级（列表）：收不收低年级（是 / 否 / 未知 + 依据）> 截止 > 与目标的契合（规则分）> 核对日期 > 来源。
- 优先级（组卡）：在做什么（主页原文摘录）> 近两年论文（可直接「为这篇建阅读卡」）> 怎么进（学长学姐卡 + 往年公开题目链接）> 敲门砖要求（对应标准）> 聚合结果（n ≥ 5 才显示）> 可以问谁。
- 状态：检索失败 → 如实写失败来源；快照 → 标「快照，核对于某日」；未知字段 → 「未知」+ 获取路径；聚合不足 → 「联系结果：数据不足（少于 5 人）」；组卡 90 天未更新 → 「可能过期」。
- 规则决定：筛选、排序、聚合是否显示；模型只做：从来源页抽取固定字段并给逐字引文，校验不过的字段丢弃。

```
┌ 机会 ─ [库] [我的看板] ──────────────────────────────────────────────┐
│ 筛：方向 AI ▾ · 类型 课题组 ▾ · 收低年级 是/未知 ▾ · 30 天内截止 □      │
│ ┌ X 组（信科 · NLP）──────────────── 核对于 09-30 · 来源 主页 ↗ ┐       │
│ │ 收大一大二：是（依据：学长学姐组卡 10-01；2025 本研公开题目 1 项）│       │
│ │ 在做：「……」（主页原文）                                       │       │
│ │ 近作：《A》↗ [建阅读卡 ✓已建]  《B》↗ [建阅读卡]                 │       │
│ │ 敲门砖：2 张阅读卡 + 1 张提案画布（标准 v1.0）  你：1/3           │       │
│ │ 联系结果：数据不足（少于 5 人）     [关注] [看组卡]              │       │
│ └────────────────────────────────────────────────────────────────┘       │
│ 我的看板：关注 3 │ 准备中 1 │ 已发 1 │ 有回复 0 │ 面谈 0 │ 进组 0 │ 没回复 0 │
└──────────────────────────────────────────────────────────────────────┘
```

- 看板拖动只改状态；「已发」要学生确认日期；「没回复」14 天后由学生确认，系统不自动判。手机上看板改为按状态分组的竖向列表。
- 组卡字段（学长学姐填，结构化）：收不收低年级、通常从什么任务开始、每周期望投入、组会频率、联系偏好（邮件 / 先找博士生）、是否愿意被问。不收对老师人品、脾气的评价（§12）。
### 7.7 套磁准备台（无线框）
- 三格：①为什么是这个组（必须指向自己对该组论文的一张阅读卡里的具体一点）②我做过什么（只能从作品中选，自动带链接）③我想做什么 / 每周能投入多少（可直接引用画布的问题）。
- 清单挑错（规则 + 模型）：是否具体到论文的某一点；作品链接能否打开；有无把「自述」写成「已证明」；长度；群发痕迹（同一段落出现在多封信里）。模型只返回「第几格、哪一句、违反哪一条」，不给改写。
- 「复制」把三格拼成纯文本，学生自己改、自己发；产品不代发、不生成正文。
### 7.8 作品与作品集
- 作品页：这件作品现在过线没有、下一版改哪一处、改了什么（版本对比）。
- 作品集公开页：让老师或博士生 2 分钟内判断「这个学生读过什么、想清楚了什么、做出了什么、多可信、能投入多少」。
- 优先级（公开页）：一句话定位（学生写）> 提案画布（主作品）> 最小测试结果 > 过程证据（决策日志摘要、轨迹链接、讲解记录）> 2 张精选阅读卡 > 已证明的阶梯步骤 > 可投入时间 > 联系方式。过程证据是给老师看的「这是他自己想的」的凭据，学生自己决定公开到哪一级。
- 规则决定：可公开的条件（过线 + 已答讲解题 + AI 使用声明齐全；画布另需通过 5 分钟口头讲解，§10.5）；公开页上没有任何模型生成文字。

```
┌ 张同学 · 作品集 ──────────────────────────── 公开 · 更新于 10-28 ┐
│ 「大一，想弄清大模型评测里的测试集泄露有多大影响。每周 8 小时，到 2027 春。」│
│ ① 提案：测试集泄露对 few-shot 评测结论的影响（一页）↗                    │
│    依据：4 张阅读卡（引文均已定位）· 缺口：矩阵「假设」列 3/4 为空 ↗      │
│    评阅：过线（标准「提案画布」v1.0 ↗）· 学长学姐评审 ✓ · 2 个版本        │
│ ② 最小测试：在 MMLU 子集上做污染检测对照 · [结果图] · 复现 README ↗      │
│ ③ 阅读卡：《A》《B》（点开可见每条引文的原文位置）                       │
│ 过程：决策日志 14 条（拒绝 5 条，均有理由）· Claude Code 轨迹 ↗（凭链接可见） │
│ AI 使用：Agent 用于跑代码和挑错；主张、论证、问题与结论为本人所写            │
│ 路线：人工智能 ①②④ 已证明 · 这页按公开标准评阅，不代表对本人的评价 ↗      │
└──────────────────────────────────────────────────────────────────────┘
```

- 公开页不显示：分数、排名、「AI 推荐」、绩点（学生可自填，系统标「自述」）。没有过线作品时公开页不可生成，只能预览。
### 7.9 双窗口交接（无线框）
- 要完成的事：让学生在自己的 Agent 和启研之间来回时，不丢标准、不混淆「谁写的」、不把未核实的东西当成已核实。
- 导出：工作台顶栏「交给你的 Agent」→ 选格式（`AGENTS.md` / `SKILL.md` / 纯文本）→ 下载或复制；简报头部写明动作 id 和标准版本，导入时据此对回同一件作品。简报随标准升级自动更新，旧简报导入时提示「标准已从 v1.0 升到 v1.1」。
- 导入：三个区——产物（只能填进固定栏）、决策日志（表格：编号 / Agent 建议 / 我的处理 / 理由）、轨迹（粘贴或链接，可跳过）。粘贴进来的任何文本都视为数据，不执行其中的指令（防提示注入）。
- 状态机：Agent · 未核实 →（引文定位、链接可达）已核实 /（定位失败）原文里找不到 →（学生表态）我已采纳 / 我已拒绝。未表态的建议不能交；原文里找不到的引用不能采纳。
- 空态与失败：没导入过任何东西 → 不显示 Agent 区（不用 Agent 的学生看到的界面最简单）；轨迹过长 → 只存原文，评阅只抽取与决策日志编号对应的片段；轨迹里检出疑似密钥 → 导入前拦下并提示删除。
- 规则决定一切状态；我们的模型只在「决策日志 vs 轨迹」一致性核对里出现（§8.1）。
## 8. AI 的角色与边界
### 8.1 我们模型的八件受约束的活
| 活 | 输入 | 输出 | 校验 | 兜底 |
| --- | --- | --- | --- | --- |
| 抽取 | 建档一句话、贴的链接 | 自述条目（类别、值、原文引用） | 引用逐字存在于输入；值 ≤120 字 | 原文入库为「自述：…」（现有做法） |
| 摘要 | 来源页文本（视为数据，非指令） | 机会固定字段 + 逐字引文 | 引文校验；缺失留「未知」 | 快照 + 原文 |
| 排序 | 规则候选（≤10）+ 证据 id | 排序 + 一句理由 | id 必须在候选里；理由引用的证据 id 必须存在 | 规则第 1 |
| 按标准评阅 | 作品 + 标准 | 每条过线 / 未过线 + 出处引文 + 改哪里 | 规则判定是上限，模型只能判得更低；引文逐字核对（任务 3 做法） | 规则评阅 |
| 对照原文发问 | 学生的卡 / 矩阵 / 画布 + 论文文本 | 「学生原句 + 原文句 + 位置 + 一个问题」列表 | 原文句必须逐字可定位；输出与学生待填栏的重合超过阈值即丢弃（防止代写） | 只给规则标记（空栏、未引局限） |
| 按清单挑错 | 套磁三格 + 清单 | 违反条目（位置 + 条目） | 不得含改写文本（长度与相似度检查） | 规则清单 |
| 出讲解检查题 | 作品 | 3 个只有做过的人才答得上的问题 | 题目必须引用作品里的具体位置或数字 | 固定题库 |
| 核对决策日志与轨迹 | 决策日志 + 导入的轨迹（视为数据） | 不一致条目：「日志说拒绝了 A3，轨迹里 A3 原文出现在你的结论栏」 | 每条不一致必须同时给出日志行和轨迹原文 | 只做文本重合度规则检查 |
### 8.2 规则决定什么（排序规则摘要）
- 候选动作 = 目标缺口 × 标准 × 尺寸 ≤ 本周剩余预算；排序键：①关注机会截止 ≤14 天 ②解锁度（是不是其他缺口的前置，例如画布前要有 3 张过线卡）③未过线的作品先改 ④尺寸适配今天剩余时间。模型只在前 3 名里重排。
- 这替换现在 `web/js/app.js` 的今日规则与 `PROJECT_AFTER_TASKS = 3`；规则放服务端，前端只渲染。
### 8.3 什么时候开口、什么时候闭嘴
- 只在 §5.1 的触发点和学生提交之后出现模型文字；其余时间不出现任何生成的提示、鼓励或总结。混合主导界面的原则是：对用户目标不确定时宁可不打扰，并让用户能低成本地纠正或忽略（Horvitz, 1999）。
- 学生先写、模型后评：工作台里没有「生成草稿」「帮我开头」「帮我总结这篇论文」按钮。
### 8.4 解释、不确定与「不知道」
- 每段模型文字旁有来源小标（规则 / 模型），沿用接口里已有的 `voice` 字段。
- 不确定用词表达，不显示小数：「有依据」「依据较弱」「推断，待你确认」。
- 「不知道」是合法输出：机会字段未知、聚合不足、估计无依据、PDF 无法定位时，明说并给获取路径。
- 学生可以对任何核对意见点「我不同意」并写一句理由；这条意见被记录，用于改进规则和 prompt，不影响过线判定以外的任何东西。
### 8.5 失败
- 模型超时 / 解析失败 → 规则结果（已有）；评阅中途失败 → 先出规则评阅，标「模型核对未完成，可稍后重跑」；来源抓取失败 → 快照 + 原因（已有）。每次调用记 {任务, 模型, prompt 版本, 校验是否通过, 耗时}（ARCHITECTURE §4 已规划），校验失败率作为周指标。
### 8.6 信任校准
- 让局限看得见：评阅页写「规则判定是上限，模型只会判得更严」；首次使用时一句话说明模型做什么、不做什么（对 AI 期望的事先调整，Kocielnik et al., 2019）。
- 抽查：每周随机抽 5% 的模型核对给学长学姐复核，不一致的样本用来改标准和 prompt。
### 8.7 学生的 Agent：边界与信任
- 学生的 Agent 不是我们的组件：我们不调用它、不读取它的账号或学生电脑，只接受学生主动导出、主动导入的内容。
- 它的一切输出都是不可信输入：引用必须过定位校验；导入文本里的指令一律不执行；它给的事实（组名、截止、数据集）以我们的数据为准，冲突时标出。
- 我们给它的只有简报（和以后经授权的只读 MCP）；简报里的诚信规则是请求，不是保证——保证来自评阅阶段的核对和真人讲解（§10.5）。
### 8.8 永远不做
- 不聊天；不替学生读论文、写卡、填矩阵、出问题、写画布、写套磁信或申请书；不编造机会、论文、引文、老师、截止；不预测「你能不能进 X 组」；不评价老师；不评价学生这个人；不把账本给任何第三方（含老师），除非学生明确公开；不用 AI 检测器判作弊（对非母语写作者有偏差，Liang et al., 2023）；不监考、不录屏、不记键盘、不强制附轨迹。
## 9. 用户模型：可见、可改、可解释
- 三类条目：已证明（由过线作品支撑，不衰减，标准升级后标版本）；自述（建档和导入，等交证明）；推断（从行为推出，默认待确认，确认前不参与排序）。现有 `source: declared | inferred | behavior` 正好对应，保留。
- 条目写「能做什么」，不写「交了多少字」：现在写回的是「完成微任务《…》：提交了 155 字的记录」，改为「已证明：能在论文里定位作者自述的局限并据此提出可检验的改动（阅读卡《…》v2）」。
- Agent 使用单列为可证明的技能：例「已证明：能让 Agent 挑错而非代写，并拦下其编造的引用（阅读卡《…》v2 的决策日志）」；只给学生自己看「被拦下的 Agent 引文数」「决策日志表态率」，不进公开页、不排名。
- 研读相关条目单列一组：读过并过线的论文数、能独立完成的卡栏（主张 / 证据 / 假设 / 局限）、矩阵论证次数、过线画布——这既是渐退的依据（§1C.6），也是学生看得见的「研究思维」进展。
- 证据呈现：每条可点开到原话 / 作品 / 评阅引文；可查「这条被哪条建议用过」。
- 衰减：兴趣类 60 天无新证据显示为「可能过时」（现规则 ×0.9/30 天，界面换成文字状态）；已证明不衰减；目标过截止后转「待你决定」。
- 改与删：可改值（标「本人修改」）、可删（软删，30 天内可恢复；之后由学生发起永久删除，产品不自动永久删除）、可导出 JSON。
- 隐私分层：私有（默认）/ 小组可见（只限你选的作品和本周交付）/ 公开（作品集）。联系记录永远私有；聚合到机会数据时同一组少于 5 人不显示，且只显示计数。上传的订阅论文全文只本人可用。
## 10. 反馈与评价
### 10.1 三个问题映射到界面（Hattie & Timperley, 2007）
- 去哪：动手前看到标准、示范，以及这件作品在目标里的位置（「这是 X 组敲门砖的第 1/3 件」）。
- 现在怎样：逐条过线 / 未过线 + 出处（作品原句、论文原句与位置）。
- 下一步：只指一处，按钮就是「改这一处」。
### 10.2 标准注册表
- 内容：阅读卡、矩阵论证、问题阶梯、提案画布、最小测试（复现报告）、套磁清单，加上任务 4 每步「做完怎样算过了」和任务 3 五条；各带版本号与签认人（目标：每个标准至少一位北大老师或博士生签认，签认人公开）。
- 判据必须可核对（沿用任务 4 纪律），例：阅读卡「局限栏至少一条引文出自论文的局限 / 未来工作段」；矩阵论证「三句俱全，且第①句点名一个具体假设」；问题「点名对象、变量、指标，并写出一个会让你放弃的结果」；画布「已知引用 ≥3 张过线卡，缺什么指向 ≥1 个格子」。
- 「值不值得做」不写成规则、也不交给模型：由学长学姐或助教用三档（值得 / 可以但要收窄 / 先别做）加一句理由评，评审人署名。
- 规则先查、模型再判、规则为上限、引文逐字核对：任务 3 已经做对，推广到所有作品类型。
### 10.3 去掉什么
- 去掉 0–100 分（`Feedback.score`），界面只显示「k / n 条过线」；去掉 `encouragement` 的空泛鼓励，换成「比上一版：多过线 1 条」这类事实。
- 评语模板禁止对人的语句（「你很有潜力」「你适合」），只写作品。
### 10.4 改的循环
- 每次提交是一个版本；评阅比较上一版；未过线不阻断做别的，但阶梯、矩阵和作品集只认过线版本。
- 第三次未过线：建议降档（独立卡 → 提示卡）或问人（§5.7）。
### 10.5 评判断，不只评产物（学术诚信嵌在流程里）
- 前提：学生有 Agent，产物本身能被代做，所以评阅的对象从「产物」扩到「判断与理解」。原则是让作假变贵、让诚实的过程变值钱——老师看重的正是过程证据。
- 引文定位：卡、画布、套磁信里的每条引用都指向原文位置；Agent 编的引用在这里被拦下（Walters & Wilder, 2023 记录的那类编造）。
- 决策日志评阅（新增标准条目）：至少列出 Agent 的主要建议并逐条表态；拒绝必须有理由；理由要指向原文、数据或标准条目，而不是「感觉不对」。评的是判断质量，不奖励「拒绝的条数」，以免被刷。
- 日志对照轨迹（可选附轨迹时）：我们的模型找不一致——日志说拒绝了，轨迹里那段话却出现在学生只能自己写的栏里。不一致不判作弊，只让该栏不计过线，并在学生自己的页面上列出。
- 只能学生自己写的栏：阅读卡的主张与「我会改什么」、矩阵三句论证、问题阶梯、画布的「缺什么」与「预期与证伪」。其余栏（方法摘要、代码、图）允许采纳 Agent 产出，但要在日志里登记。
- 理解检查分两档，不监考：①每件作品 3 个讲解题（在线、无时限，答案进作品集）——它能被 Agent 代答，所以它的作用是自我解释的学习收益（Chi et al., 1994）和增加作假成本，不是关卡；②画布进作品集前，由学长学姐或小组同伴做 5 分钟口头讲解（线上或线下），这是唯一的硬关口，由真人把关而不是由系统监视。
- 过程可信度标签（公开页显示，学生自选是否公开）：「引文已核对」「附决策日志」「附真实轨迹」「通过口头讲解」。不显示「可疑」之类的负面标签——没有某项只是少一个标签。
- AI 使用声明：结构化填写（用了什么工具、做了哪部分），与决策日志合并展示；过程痕迹包括版本历史和可选 git 链接，作品集展示版本数。
### 10.6 同伴评阅
- 小组每周互评一份，只能用同一标准：选一条标准 → 引作品原文 → 写一条建议；不打分（Topping, 1998）。阅读卡的互评特别有效：同组两人读同一篇时，矩阵会把两人的卡并排，差异本身就是讨论材料。
- 被采纳的建议在被评者的下一版里自动标出，给评阅者事实性回馈；互评质量不排名。
## 11. 动机与长期使用
### 11.1 立场
- 这群人外在动机强，不需要哄。自我决定论区分的关键不是「内在 vs 外在」，而是「自主 vs 受控」：被自己认同的外在目标可以持久，被内疚和比较驱动的代价高（Ryan & Deci, 2000）。设计目标：把「进组 / 立项 / 保研」接到「我选的、看得见进展的、证据属于我的」路径上，而不是加更多外在刺激。他们要的是速度、下一步的清晰度、看得见的进展、诚实的位置。只和标准比，不和人比；给「参照」，不给「排名」（掌握目标结构，Ames, 1992）。
### 11.2 机制取舍
| 机制 | 决定 | 依据 / 理由 |
| --- | --- | --- |
| 就绪度进度（离目标还差几件） | 做 | 越接近目标越努力（Kivetz, Urminsky & Zheng, 2006）；标准参照，刷不了 |
| 研读进展（过线卡数、可独立的卡栏、画布） | 做 | 让「会读会想」这件慢事有可见的进展；也是渐退依据 |
| 截止雷达 | 做 | 真实截止是最强的外在节奏，不是人为制造的稀缺 |
| 本周 3 个动作 + 时段 | 做 | 执行意图（Gollwitzer & Sheeran, 2006）；大规模下效果有限，只做轻量版（Kizilcec et al., 2020） |
| 小组（4–6 人，周交付 + 互评） | 做，可退出 | 同伴评阅（Topping, 1998）；可见的成功同伴做法在 MOOC 中提高完成率（Davis et al., 2017）；只显示「本周交了没有」，不显示数量 |
| 参照轨迹（同意公开的学长学姐时间线） | 做，标 n 和时间 | 「成功者做了什么」比排名有用（Davis et al., 2017）；同时展示没进组也有收获的轨迹，抵消幸存者偏差 |
| 公开作品集 | 做，默认关 | 展示的是作品本身，比的是标准 |
| 排行榜 | 不做 | 一学期内降低内在动机、满意度和成绩（Hanus & Fox, 2015）；精英校里相对位置压低自我概念（大鱼小池效应，Marsh, 1987），这群人本来就在强池子里 |
| 连胜 / 连续天数 | 不做 | 奖励「出现」不是「交付」，制造内疚；科研是周节奏 |
| 经验值、等级、徽章 | 不做 | 游戏化整体效果取决于设计（Sailer & Homner, 2020），外在奖励会削弱对有趣任务的内在动机（Deci, Koestner & Ryan, 1999）；我们的里程碑就是过线作品 |
| 可变奖励、限时稀缺、「X 人已超过你」 | 不做 | Hooked 模型（Eyal, 2014）的套路，制造焦虑而非交付；在内卷语境下放大非理性竞争（Liu et al., 2022） |
| 通知 | 每周 ≤3 条默认 | Mark et al., 2008；Weiser & Brown, 1996 |
### 11.3 掉队与回来
- 暂停是正常操作（§5.8）；回来先看「你不在的两周」（§5.10）；不追问原因。
### 11.4 交给真人，不假装是导师
- 每个目标的终点都是人：组、导师、学长学姐。产品负责让学生「带着画布和好问题」到人面前：套磁准备台、面谈准备动作、答疑问题模板。有效科研指导的要素（如明确期望、及时反馈、支持独立性）来自真实的指导关系（Pfund et al., 2016; NASEM, 2019），产品不冒充。
- 试做任务是合法的边缘性参与：从组里真实但低风险的小事做起，逐步进入核心（Lave & Wenger, 1991），前提是它首先是学习任务（§12）。
- 学长学姐答疑：15 分钟预约，提问必须用模板（我在做什么 / 卡在哪 / 已经试过什么）；模板也降低了开口求助的面子成本（对 Hwang, 1987 面子与人情框架的推论，「未核实」其对本场景的适用性）。
- 老师 office hour、课程助教、院系本科教务在「卡住了」和路线上作为一等选项出现，附「怎么问」模板。
- 产品成功的一部分是被「毕业」：进组后从主线退场（§5.11）。留存靠学长学姐角色和新目标，不靠把人留在产品里。
## 12. 伦理与风险（围绕野心而不是脆弱）
- 压力放大：缺口一直可见可能成为持续的焦虑源。对策：周预算上限（超出提示，不默认塞满）；考试周自动减量；没有「别人比你快」；校准写依据也写不确定。
- 内卷军备竞赛与凭证膨胀：如果人人都带作品集套磁，门槛只会抬高（Collins, 1979；内卷作为社会规范推动学历追逐，Chen, Zhou & Yang, 2024）。对策：标准是「过线」而非「越多越好」，作品集最多展示 1 张画布 + 3 件作品；同时在追的联系 ≤3；不鼓励「大一一作」这类离群目标，路线默认终点是「进组并有贡献」；指标不奖励联系数量和卡的数量。
- 学术诚信：不代写、不替读、引文定位、AI 使用声明、讲解检查、版本痕迹；不做「论文辅导」「挂名」撮合；学长学姐的试做任务不得以署名换劳动。学位法第三十七条把学位论文或实践成果的代写、剽窃、伪造列为不授予或撤销学位的情形；记者卧底的「论文工厂」用 AI 批量代写（新京报, 2024）。这是对机构的护城河，不是负担。
- 学生的 Agent 成为代写者：简报里的诚信规则挡不住决心作假的人。对策是 §10.5 的组合（只能自己写的栏、引文定位、日志对照轨迹、真人口头讲解），并接受残余风险：老师最终还会面谈，产品不假装是监考。
- 监视与过程证据的边界：轨迹可能含个人信息、同学姓名、密钥。对策：轨迹永远可选、导入前剔除疑似密钥、学生决定公开到哪一级、可随时删除；不做监考、录屏、键盘记录、浏览器插件采集；不因「没附轨迹」降低任何评价，只是少一个可信度标签。
- 给学生 Agent 的数据出口（以后的 MCP）：账本一旦被授权读取，就进入第三方模型服务商。对策：只读；按类别授权（工具包与机会数据可默认开，账本与联系记录默认关）；可随时撤销；访问留日志给学生看；授权页写明数据会离开启研。
- 提示注入：导入的轨迹、来源页、论文文本都可能含有指令性文字。对策：一律当数据处理，不拼接进任何会被执行的指令位置；我们模型的输出必须引用原文位置，否则丢弃。
- 刷指标：任何被奖励的数字都会被刷（Campbell, 1979）。对策：北极星是「过评阅的证据」，评阅规则为上限，讲解检查，卡的数量不进任何公开展示。
- 本科生被当免费劳力：试做任务 ≤3 小时、必须有学习标准、不得是组里的生产性杂活；学生可匿名举报；超时任务下架。
- 老师被刷屏：同时在追 ≤3；清单查群发痕迹；某组明确不收本科生时机会置灰，不再推荐。
- 公平：老师回复套磁邮件存在按姓名所示性别与族裔的偏差（Milkman, Akinola & Chugh, 2015）；第一代大学生参与科研更少（Ke et al., 2022）。对策：滩头选缺人脉的人；作品集把注意力从身份移到作品；答疑按需分配；§15 分人群看结果。
- 版权：订阅论文全文只本人可用、不共享；工具包只存元数据和短引文并指明出处（著作权法第二十四条）；不接入任何盗版文献来源；只抓公开页面，需要登录的校内系统（如本研系统）不抓取，只允许学生录入链接和备注。
- 数据与隐私：联系记录、未公开作品和上传论文是敏感数据；默认私有；聚合 k ≥ 5；不卖、不给机构；可导出、可删。
- 诽谤与人身评价：组卡只收结构化事实字段，不收对老师的评价；更正走「申请更正 + 来源」流程。
- 误导方向：热门方向会吸走注意力。对策：方向排序只用学生自己的证据和目标；「先摸清方向」强制跨两个方向。
- 对模型的过度信任：核对意见都带原文位置，学生可以「不同意」；估计标「估计」；不做录取预测。

## 14. 落地路线（2–3 周，5 人 + AI 编码代理）
### 14.1 原则
- 先建会积累的结构（工具包、引文校验、账本、标准、机会数据、作品集、小组），最后才碰模型措辞。简报是标准的副产品（生成脚本），成本低、对用户价值高，排在第 2 周。
- 一个方向、一个子领域打穿：人工智能（信科）+ 一个子领域工具包；其他方向保持现状。
- 每周五在真学生身上跑一次（哪怕 3 个人），先展示结果再改代码（团队规则）。

### 14.3 推迟 / 砍掉
- 推迟：给学生 Agent 的只读 MCP 接口（先做好授权与隐私设计）、日志对照轨迹的模型核对（先用文本重合度规则）、模型的对照原文发问（先规则标记）、知网与中文 PDF 稳健抽取、第二个工具包、组卡的学长学姐认证（先用邀请码）、外部通知渠道、更多方向的路径、首页动画、手机原生、付费。

### 14.4 课程演示脚本（也是产品故事）
- 建档（1 分钟）→ 工具包示范卡（30 秒）→ 学生在原文上选中引文填卡，引文错误被当场标出（1.5 分钟）→ 把同一张卡「交给 Agent」，导入它的建议，一条编造的引用被标红、一条被学生拒绝并写理由（1 分钟）→ 4 张卡生成矩阵，空列显形，写三句论证（1.5 分钟）→ 提案画布与学长学姐评审意见（1 分钟）→ 作品集公开页（30 秒）→ 机会组卡与看板（1 分钟）→ 正面对比预实验结果（1 分钟）。关掉模型重跑填卡与矩阵两步，证明结构独立于模型。
## 15. 怎么验证
### 15.1 原则
- 先验证会让我们全盘重来的市场假设（§1A.6），再做可用性。
- 每个测试开测前写下「什么结果会让我们改设计」的阈值，避免事后解释。
- 不对老师做欺骗性的「假学生邮件」实验；老师侧一律用知情同意的评审。
- 伦理：知情同意、随时退出、数据匿名；不对老师做欺骗实验；结果数据只用于聚合；被试回报不与「是否进组」挂钩；T2 中 A 组结束后可免费使用启研。
### 15.2 测试清单
| 编号 | 验证 | 方法 | 样本 | 测什么 | 改设计的判据 |
| --- | --- | --- | --- | --- | --- |
| T1 | R1 老师看不看作品集 | 盲评 + 出声思考：每位评审看 8 份套磁材料，顺序随机：A 只有自述简历；B 简历 + 最小测试作品；C 简历 + 提案画布 + 测试；D 通用 LLM 润色过的信；E 同 C 再加过程证据（决策日志 + 轨迹链接 + 讲解记录） | 北大老师、博士后、博士生 10–15 人，跨 2–3 个组 | 「愿意回复 / 愿意见面」、决定用时、点开了什么、对画布的评价 | B、C 不优于 A 或评审不点链接：作品集改为邮件内一页纸，并与评审共设计字段；D 优于 C：信件文字比作品更重要，套磁准备台优先级上调；C 明显优于 B：研究思维层是主卖点，对外叙事以画布为中心；E 不优于 C：过程证据对老师没有增量，作品集里把它折叠起来、降低学生附轨迹的激励 |

| T6 | R5 供给侧 | 真实邀请学长学姐写组卡、核对工具包、评画布 | 大三以上及研究生 20 人 | 完成率、用时、动机访谈 | 完成率低：字段砍半，或由团队做 5 分钟访谈代录（注明来源） |
| T7 | R6 不代写的立场 | 观察而非假门（学生本来就有 Agent）：在 T2 的 B 组与 T5 中看简报诚信规则被删改的比例（从轨迹看）、「只能自己写的栏」因与 Agent 输出重合而不计过线的比例；离开者访谈 | T2、T5 全部被试 | 上述比例、流失、访谈中对「不代写」的态度 | 流失高且原因是「太麻烦」：降低导入与日志摩擦，不改立场；原因是「想要代写」：接受这部分用户流失，首页更早讲清「为什么不代写对你更好」（学位法、作品可信度） |
| T8 | R7 小组 | 3–4 个小组跑 3 周，对照同期单人 | 每组 4–6 人 | 每周过评阅的交付数；竞争心理用 Liu et al. (2022) 量表相关分量表前后测（适用性需核对）；访谈 | 交付不升而压力升：小组改为可选、只保留互评 |
| T9 | 可用性 | 出声思考：建档 → 第一张卡；矩阵 → 论证 → 画布；机会 → 看板 → 套磁准备台 | 每轮 5–8 人，两轮 | 完成率、错误、用时、SUS（Brooke, 1996） | 关键流程完成率低于团队事先设定的线：重做该流程再测 |

- 可选的次要测量：科研自我效能与科学身份认同的简短量表（Chemers et al., 2011; Estrada et al., 2011），中文版需核对。
### 15.3 上线后每周看
- 北极星：每周过评阅的证据数 / 活跃用户。
- 研读：过线阅读卡数、独立档占比、矩阵论证数、过线画布数、学长学姐评「值得做」的比例。
- 漏斗：激活率（7 天内过线阅读卡）、W1–W4 留存、作品集外链打开、小组邀请接受。
- 结果：联系 → 回复 → 面谈 → 进组 / 立项（自报 + 可选凭据），按人群（第一代大学生、地区、性别）分看，检查是否扩大了不平等。
- 双窗口：导出简报的动作占比、导入率、决策日志表态率、Agent 引文被拦截率、附轨迹比例（只看趋势，不设指标目标，避免变成监视）。
- 质量：引文自动定位率、模型校验失败率、学长学姐抽查一致率、机会数据过期率、工具包复核日期。
- 伤害：每月一次三题压力与睡眠自评（自愿），上升时检查预算与提醒规则。
