# DESIGN_SPEC · 启研设计规范 v1.1

> 从旧 Demo「学科瞭望」视觉体系提炼，是本项目**唯一的 UI 视觉权威**。
> 所有新页面/组件必须遵循本规范；规范未覆盖的，参照现有页面类推并回填本文档。
> 实装参照：[web/css/styles.css](../web/css/styles.css)（`:root` 变量区为唯一色值/字体来源）。

---

## 1. 设计立场

面向大一大二的学术工具，气质 = **安静、可信、有书卷气**：

- 低饱和底色 + 一个主色（青绿 teal），信息密度友好；
- 克制的圆角与阴影，不用毛玻璃、不用重渐变、不做暗色模式（V1）；
- 事实与证据永远高亮可辨（引用、来源、置信度是产品核心，必须醒目但不刺眼）。

## 2. 色彩（token 与代码一一对应，唯一来源是 styles.css 的 `:root`）

| Token | 值 | 用途 |
| --- | --- | --- |
| `--bg` | `#f5f2ea` | 页面底色（纸面） |
| `--surface` | `#fffdf8` | 卡片 / 面板 / 输入框 |
| `--sunken` | `#eeeadf` | 悬停底、AI 气泡、提示块 |
| `--ink` / `--ink-2` / `--ink-3` | `#1c2823` / `#4d5a54` / `#85908a` | 正文 / 次要 / 辅助文字，只用这三级 |
| `--line` / `--line-strong` | `#e4dfd2` / `#d2cbba` | 分隔线 / 可交互元素描边 |
| `--teal` / `--teal-soft` | `#0f6e65` / `#e2efea` | **主色**：主按钮、当前节点、用户气泡、做到 ✓ |
| `--coral` / `--coral-soft` | `#b4532f` / `#f7ebe4` | 只给「未做到 / 删除 / 新写入的行为证据」 |
| `--gold` / `--blue` / `--violet` | `#a07424` / `#2f5aa8` / `#6b4fb0` | 事实类别圆点，不做大面积底色 |
| `--night*` | `#0c0f0e` 等 | 仅首页夜色；`--night-accent` 为点线图主色，`--night-mark` 为序号游标 |

**配色纪律**：一屏只有一个视觉重点（今日=建议卡，方向=树上「你在这里」，任务=提交按钮）；主色面积 ≤ 20%；不加渐变底、不加光晕（唯一例外：首页夜色的粒子辉光与图形后柔光用 canvas 表达、每屏一主题色，2026-10-08 由用户定稿）。

## 3. 字体

| 层级 | 字体 | 用法 |
| --- | --- | --- |
| 标题/数字 | `--serif`：Source Serif 4 / Noto Serif SC → 宋体回退 | 工作区标题 30px、卡片标题 20–26px、分数 |
| 正文/UI | `--font`：系统字体（PingFang SC / 微软雅黑） | 正文 15px/1.7，辅助 13px，标注 12px |

- 衬线字体走 `fonts.googleapis.cn` 镜像且不阻塞首屏；正文不加载网络字体（国内网络下 Google Fonts 会卡住首屏）；
- 数字用 `tabular-nums`。

## 4. 形状 / 间距 / 动效

- 圆角：`--r-lg 14px`（面板）/ `--r-md 10px`（按钮、输入）/ `--pill`（chip、节点）；
- 间距只用 `--gap-1..7`（4/8/12/16/24/32/48）；页面统一左对齐，左边距 48px（窄屏 20px）；
- 不用投影区分层级，用 1px 描边；只有抽屉和弹窗有投影；
- 动效：进入 `riseIn` 0.35s、新事实 `factIn` 珊瑚底淡出、树 `linkIn` 连线生长；过渡统一 `0.15s`；`prefers-reduced-motion` 时全部关闭。
- 首页换屏：**只剩文字与粒子**（参考彩色 WebGL 粒子站，2026-10-08 由用户定稿）——**每屏一个主题色**（起点青 `rgb(127,209,194)` / 画像蓝 `rgb(143,189,246)` / 方向紫 `rgb(195,174,245)` / 任务金 `rgb(242,205,126)` / 反馈珊瑚 `rgb(242,160,138)` / 成长绿 `rgb(164,222,138)`，见 `app.js` 的 `TONES`），主题色用于：粒子强调笔画、图形后一团柔光（径向渐变 α0.2）、背景向主题色微染 9%、文字点缀（kicker、`.snap-no` 大编号 12% 透明度染色、滚动提示线、直达按钮 hover 边）——全部随滚动相位在相邻两色间**连续过渡**。**文字与图形逐屏左右对调**（偶数屏文字左/图形右，奇数屏反之，转场时粒子散开途中锚点横移换位）：左列边距 `max(120px, 13vw)`（更靠中、离左缘进度条更远），右列边距 `max(88px, 9vw)`、竖直位置由 JS 写入 `top` 与图形中心对齐（整列放不下时向上收敛，底部留 24px 不裁字），显隐由 JS 按滚动相位渐变——行进后段（聚形近完成）渐入、开始滚向下一步即渐出，挂 `.lit` 后块内两段进场：标题先出现、内容（导语 15px / 要点 12–13px）延迟 0.35s 再出现；标题纯白 #fff 带轻微白光晕（text-shadow 18px α0.28）。**左缘纵向进度 `.land-steps`**：顶部当前步号（mono 13px、染主题色、随屏跳 00–05，序号从 0 计）+ 中间 2px 轨道（随滚动连续生长、染主题色）+ 底部 `/ 05` 总步数（mono 11px）。**粒子为发光 sprite**（**热芯型**径向渐变预渲染：核心占 45% 全亮、外围快速衰减，逐点 drawImage 避开逐点 shadowBlur；每屏主题色各一张）：点距 1.6px 高密度密排，**细粒子沿笔画法线横向散布 ±2.6×dot**，铺成有颗粒感的粗笔画（普通混合、颜色分明，转场时法线插值归零收成细线飞走）；粒径随聚形度 0.55–1.6 倍基准再乘 0.75–1.35 的逐粒抖动，光晕半径只有芯的 2.2 倍——聚形后是**发亮锐利的彩色实线**；换图途中先**均匀散布全屏**（亮度降到 α0.28、点半径缩到 0.6×），随后聚回对侧图形锚点——亮度与粗细随聚形度渐增、聚拢完成时最强；开场从全屏散布聚成首图，文字在聚形后半段才出现。**步进叙事（不自由滚动）**：一次滚轮（|δ|>12）/滑动（>46px）/方向键·翻页键·空格 = 一整段剧本——粒子散开聚形换位（**固定时长 4.2s 的 smoothstep 时间线**，帧率无关、全程可见运动）→ 文字两段进场 → 相位差 0.02（文字刚收尾）即起播聚形后动画（约 1.6s，与收尾并行）——**「滚动以继续」提示与动画同时亮、输入同时解锁**（开场聚形 2.2s 走完之前剧本不启动，00 屏的过程可见）；`.land-hint`：12px 文字以 2.4s 周期缓慢渐变发光染主题色 + 下方小箭头 chevron 同步发光微沉浮（尾屏不出现）；**`.land-skip` 右上角「跳过，直接开始」下划线直达（触发 `beginExperience` 进登录，除尾屏外全程可见）**；期间 `busy` 锁输入、连续滚动只记一步；`.land-snap` 不滚动（`overflow:hidden`），六个 `.snap` 绝对定位叠满视口，显隐由 JS 按相位控制，`.land-steps` 进度轨道随换屏相位连续生长。**聚形后动画**（`FIG_ANIMS`，笔画按 `part` 分组、`sampleSketch` 记 `sid`，进度 `actCur` 由剧本播放，reduced-motion 直接置 1）——00 绿门板绕自身左铰链**带透视向里推开 78°**（远端向铰链收拢、向门高中线收缩，白门框不动），门内地板两条收向消失点的透视线随开门渐显、01 问号绕底部 ±8° 轻摆（时间驱动）、02 指北针以**正北为中心在相邻两刻度（东北—西北）间**来回摆（时间驱动）、03 时针**顺时针转 240°** 回到 12 点、金色进度弧（整圈预采样）**随时针扫过的位置逐渐显出**、04 第三条待办圈形变成对勾并换本屏主题色、05 树上 R→A→A2→C2 四个节点依次点亮（环粒子变亮变大 + **环内填实心发光**：实心核 blob α0.85 + 柔光晕 α0.3）。背景分六层叠出丰富度（全部 canvas、DOM 文字在其上不受影响）：①**氛围光斑**——四团大范围色斑几乎铺满画面（图形后主光斑 α0.2 + 本屏色 ×2 α0.1/0.07 + 下一屏色对角 α0.09）缓慢漂移；②**星座网**——24 个节点小幅漂移，近邻（< 0.22×min(W,H)）之间牵起随距离淡出的 1px 细线（α≤0.14），背景有可辨的图案结构；③**星尘三层**——远景细点（~74 颗 α0.035–0.09、漂移 0.5×）/ 中景点（~34 颗 α0.05–0.12、1×）/ 近景 bokeh 软斑（13 颗 r6–16、α0.028–0.06、1.7×）；④**背景回声**——当前图形放大 2.1 倍铺在画面中心后面（每 3 颗画 1 颗、α≈0.15），淡而可辨的大轮廓随内容切换；⑤**暗角**——径向渐变四角压暗至 α0.18；⑥**胶片颗粒**——静态噪点瓦片以 `overlay` α0.08 铺满。除注明外均随主题色渐变、reduced-motion 静止、静止期 ~12fps 低频心跳。三档视口：≥1280 桌面与 920–1279 中屏图形随剩余宽度自适应（中屏内容列收窄到 360px），<920 图形收到上半屏居中、文字单列在其下。

## 6. 文案与内容规范

- 产品语气：像一位**熟悉又克制的学长**——陈述事实、给出理由、不煽情不卖课；
- 所有 AI 产出必须带理由，UI 上对应「为什么是你 / 证据」区块，禁止无来源断言；
- 检索失败必须如实展示失败（`.course-status` 文案模板：「检索失败（如实说明）：…」），**不许编造兜底数据**；
- 「不知道」选项永远合法且不加负面措辞；
- 数字/时间用半角；中文标点为主。

## 7. 布局

- 侧栏 216px + 主栏；主栏内容宽 ≤ 880px（方向页放宽到 1240px 给树），左对齐；<920px 侧栏变顶栏、单列；
- 主工作区两栏 `.two-col`（1.6fr : 1fr）：左主内容、右辅栏（实时记录/治理原则）；移动端叠放；
- 列表卡片网格 `.dir-cards`：`repeat(auto-fit, minmax(300px, 1fr))`。

## 8. 变更流程

改本规范 = PR + 在 [CHANGELOG.md](CHANGELOG.md) 登记。新增颜色/组件必须先在 styles.css 里以 token 形式落地，再回填 §2/§5。
