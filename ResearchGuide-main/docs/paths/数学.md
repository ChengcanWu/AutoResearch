# 数学 · 从入门到可以开始做小研究

> 方向：数学 ｜ 负责：乙 ｜ 链接核对日期：2026-09-30
> 终点定义：能**读懂公开材料**、能**写出别人能检查的证明**、能**独立完成一个小问题的完整循环**（提出—检验—修正），产出 3–5 页可给别人看的笔记。
> 不承诺：做出新定理、写出可发表论文。

### 第 1 步 · 把「显然」拆成步骤

- **为什么是这一步，而不是更后面的内容**：这是后面一切的地基。卡点在「我会算题，但一写证明就写不下去」——不是知识不够，是不知道每句话的合法性从哪里来。跳过它直接学分析，会变成背定理。
- **先弄懂什么**：定义、量词（对所有 / 存在一个）、反例、直接证与反证。
- **做完怎样算过了**：交 5 道证明题，**每一行注明依据**（用了哪条定义、还是某条已证事实）；再对一个错误命题举出一个**落在定义里**的反例。
- **依据**：Polya《How to Solve It》出版社页 <https://press.princeton.edu/books/paperback/9780691164076/how-to-solve-it>；现有树的 `定义` / `证明` 两支即可用。
- **对应现在树上的哪个节点**：**保留**——`证明是什么`（root）及其下 `定义`（对象 / 说法）、`证明`（直接证 / 反证）。

### 第 2 步 · 把极限说严格

- **为什么是这一步，而不是更后面的内容**：第 1 步会写证明，但一碰到「趋近」「无穷多」「任意小」就说不清——因为还没有实数与极限的严格定义。这是数学里**第一次真正处理无穷**，也是分析、概率、数值的共同语言。
- **先弄懂什么**：上确界、序列与收敛、ε-δ 量词顺序、完备性（单调有界 / 柯西 / 确界原理的等价）。
- **做完怎样算过了**：写出完备性**两条等价表述并互推**；独立完成 3 道 ε-δ 证明，每道附一句「这个 δ 是怎么找到的」。
- **依据**：MIT 18.100A 实分析 <https://ocw.mit.edu/courses/18-100a-real-analysis-fall-2020/>；Tao《Analysis I》第 3 版 <https://link.springer.com/book/10.1007/978-981-10-1789-6>。
- **对应现在树上的哪个节点**：**建议新增**。现有树停在「证明怎么写」，没有「数学对象是什么」这一层，这是最大的一处跳步。

### 第 3 步 · 线性代数：矩阵是映射，不是表格

- **为什么是这一步，而不是更后面的内容**：第 2 步给你的是「一维的严格性」。高维对象要靠线性代数才能说话；它同时是数学内部（泛函、表示论）和外部（统计、机器学习、计算）的公共接口。放在这里而不是更早，是因为懂了极限才看得懂「逼近」这类论证在做什么。
- **先弄懂什么**：向量空间与子空间、线性映射、基与维数、秩、特征值与对角化。
- **做完怎样算过了**：① 用**基变换**解释相似矩阵为什么描述同一个映射；② 说清秩和特征值在几何上各是什么；③ 用 numpy 做一次 PCA 并解释你得到的两个主方向。
- **依据**：MIT 18.06 线性代数 <https://ocw.mit.edu/courses/18-06-linear-algebra-spring-2010/>；3Blue1Brown 线性代数系列 <https://www.3blue1brown.com/topics/linear-algebra>（先建立图像，再回到严格定义）。
- **对应现在树上的哪个节点**：**建议新增**；同时把现有 `结构` 一枝（`关系`、`不变量`）上提到这一步的入口——不变量正是线代和后续代数的核心提问方式。

### 第 4 步 · 概率与统计：学会带着不确定性说话

- **为什么是这一步，而不是更后面的内容**：前三步处理的是确定对象。科研里更常见的情形是「数据有限、结论有误差」。这一步把**总体与样本**分开，是后面任何实证工作的前提。
- **先弄懂什么**：概率空间、条件概率与独立性、随机变量与期望方差、大数定律与中心极限定理、估计量与置信区间、假设检验的基本逻辑。
- **做完怎样算过了**：设计一个从总体到样本的**完整推断例子**（数据可以是模拟的），写清假设、结论，以及「什么情况下这个结论会不成立」。
- **依据**：MIT 18.05 概率统计（Spring 2022）<https://ocw.mit.edu/courses/18-05-introduction-to-probability-and-statistics-spring-2022/>；偏理论的替代：MIT 18.600 概率与随机变量 <https://ocw.mit.edu/courses/18-600-probability-and-random-variables-fall-2019/>；偏应用的替代：MIT 18.650 应用统计 <https://ocw.mit.edu/courses/18-650-statistics-for-applications-fall-2016/>。
- **对应现在树上的哪个节点**：**建议新增**。现有 `stat` 是并列的独立领域，在数学路径里建议标为「横向补充」，而不是主干步骤的替代。

### 第 5 步 · 读论文：把定义依赖画出来

- **为什么是这一步，而不是更后面的内容**：前四步是课内材料，写法是「为学习者整理过」的。研究材料不是——卡点从「不会证」变成「读不下去，不知道读到哪算到哪」。这一步解决的是**阅读方法**，不是新知识。
- **先弄懂什么**：定义嵌套怎么破、如何区分主定理与技巧性引理、读不懂时该往前补哪一层、笔记记什么（记依赖关系，不抄原文）。
- **做完怎样算过了**：选一篇公开的综述或讲义（arXiv 上的 expository 文章、或 AMS Notices 一类介绍性文章），画出**一页概念依赖图**，并写出「我还需要补的 5 个前置」。
- **依据**：Keshav《How to Read a Paper》<https://web.stanford.edu/class/ee384m/Handouts/HowtoReadPaper.pdf>；Tao 的职业建议页（含读论文、做研究、找问题）<https://terrytao.wordpress.com/career-advice/>；arXiv 数学最新列表（用来找公开综述）<https://arxiv.org/list/math/recent>。
- **对应现在树上的哪个节点**：**建议新增**。

### 第 6 步 · 做一个小问题：从「读懂」到「做出」

- **为什么是这一步，而不是更后面的内容**：读完论文容易停在「我理解了」。研究需要跑一次完整循环：提出问题 → 先猜 → 检验 → 发现猜错 → 修正。这一步把循环压到一个学期内能跑完的规模。
- **先弄懂什么**：怎么把问题缩到一学期可检验；怎么对待「猜错」（猜错本身是有效结果）；怎么把过程写成别人能看懂的笔记。
- **做完怎样算过了**：交一份 **3–5 页笔记**：问题陈述 + 已知结论 + 一个**完整算出来/证出来的例子** + 一处猜测与它的反例检验。替代形式：完整做出 Putnam 中的一道题，并写清思路是怎么找到的。
- **依据**：Putnam 真题档案 <https://kskedlaya.org/putnam-archive/>（题目来源与自测）；《The Princeton Companion to Mathematics》<https://press.princeton.edu/books/hardcover/9780691118802/the-princeton-companion-to-mathematics>（找题目背景）；Lean 社区 <https://leanprover-community.github.io/>（把证明交给机器检查，是一种很苛刻的「过关」方式，可选）。
- **对应现在树上的哪个节点**：**建议新增**——现有树没有「从读到做」的转换层。
