# knowledge/minor · 辅修 / 双专业知识包

从《北京大学本科辅修双专业培养方案（2025）》抽出来的结构化知识：**院系 → 专业 → 双专业/辅修 → 学分量 → 课程表 → 替代课程**。
回答的问题跟主修那一层不同：不是「我在哪个专业」，而是**「我在主修之外还修了什么、要修多少学分、主修课重复了拿什么替代、能不能算数」**。

- 主修层（文科卷 + 理科卷）：`knowledge/curriculum/`
- 数据来源：《北京大学本科辅修双专业培养方案（2025）》，216 页；含 p5–10 的《辅修/双专业互斥一览表》与 p13 起 98 个章节
- 生成命令：

```powershell
# 1) 抽章节（约 3 分钟）
python tools/curriculum/minor_extract.py --pdf "<辅修双专业.pdf>" --out knowledge/minor
# 2) 定位句：切批次 → 交给 LLM 压成 ≤40 字 → 合并
python tools/curriculum/minor_extract.py --out knowledge/minor --batches 4 --batch-dir .work/minor_distill
python tools/curriculum/merge_intros.py --out knowledge/minor/intros.json --dir .work/minor_distill
# 3) 出卡片与抽检表
python tools/curriculum/minor_extract.py --out knowledge/minor --cards --intros knowledge/minor/intros.json
python tools/curriculum/review.py --kb knowledge/minor --minor --out docs/curriculum_minor_review.md
```

| 文件 | 内容 |
| --- | --- |
| `catalog.json` | 98 条：院系 / 专业 / 类型（双专业·辅修） / 总学分 · 必修 · 选修 / 授予学位 / 课程数 / 替代课程数 / 来源页 |
| `cards.json` | **卡片层**（给 AI 读）：类型 + 学分量 + 一句定位 + 核心课程 + 替代课程 + 修读要求 |
| `plans/<院系>-<专业>专业<类型>.json` | 单章节：简介/培养目标/培养要求原文、学分、按模块归类的课程表、`说明` 后的替代课程表、书内+PDF 页码 |
| `intros.json` | 定位句成品（98 条，≤40 字，见 `docs/curriculum_minor_review.md` 抽检 + 待重点看的 20 条） |

## 读数据前先知道的四条

1. **类型只有两种**：`双专业`（≥40 学分，含部分选修）与`辅修`（≥30 学分，基本全是核心课）。
   两者是同一份原文里的两节，双专业的定位句写得比辅修深一层。
2. **`替代课程` 是这份数据独有的**：原文「说明」后面列了替代表——主修已经修过同名必修课时改修这些课，
   才算完成。答复「我主修修过这门，辅修还要不要修」时必须用它。有替代表的是 10 条章节。
3. **同名专业在不同院系是两份方案**：`环境科学`（城市与环境学院 / 工学院）、`经济学`（国家发展研究院 / 经济学院）
   课程和学分都不一样，卡片 key 因此带上院系（`工学院 环境科学（双专业）`），别把它们合成一条。
4. **`核心课程` 的取法**：模块编号 `1.x` 或标题带「必修」的都算必修；辅修章节如果整张表没有模块标题
   （法学、社会学、行政管理、艺术史论、机器人工程），就按「整表都是必修」处理——辅修本来就清一色核心课。
   98 条全部有核心课程（最少 8 门）。
5. **学分区间与 ≥ 号**：`总学分 ≥40学分`、`选修 ≥8学分` 是原文写法，照抄，不要取中值。

## 纪律与已知边界

- 只抽原文；`授 予 学 位` 这类无来源的空字段就留空（辅修一律不授学位，43 条有学位写的全是双专业）。
- 定位句只依据该节的「专业简介 / 培养目标 / 核心课程」，师资、沿革、就业一律不进；
  原文只有套话时写空串（见抽检表末尾的「信息稀薄」清单）。
- **互斥一览表（p5–10）没有结构化**：原文是双栏排版，`extract_text` 出来的次序是交错的，
  强行切表会造出一堆错行。这一段的用途（哪些专业不能同时修）目前只能回原 PDF 查。
- 章节页眉只印在奇数页，院系归属用的是**目录里的院系起始页区间**；目录缺行时会退化成「最近的页眉」。
